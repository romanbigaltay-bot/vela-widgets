# ST-0405-02 — UI таймера

## Цель

Один взгляд — понятно, сколько осталось и как управлять.

## Реализация

1. Кольцо: SVG `r=52`, `stroke-dasharray = 2πr`, `dashoffset` по прогрессу,
   толщина 2 px, цвет `--accent`, фон `--track`.
2. Цифры в центре: `t-display` (32 px), tabular; подпись фазы (`t-caption`,
   `--text-faint`).
3. Кнопки: `Старт/Пауза` (primary) + `Сброс` (ghost); пресеты — чипы в один ряд.
4. Клавиатура: `Space` — старт/пауза при фокусе на виджете, `R` — сброс.
5. Завершение: пульсация 3 с (`--accent-glow`), затем статичное состояние
   «готово» до сброса.

## Критерии приёмки

- AC-1 Кольцо не «дёргается» (обновление раз в секунду, плавный `transition` 1s linear).
- AC-2 Все элементы доступны с клавиатуры, фокус-кольцо видно.
- AC-3 При 120×120 кольцо и цифры помещаются без обрезки.

## Тест-план

TC-0405-03 + визуальные скриншоты 3 состояний.

## Риски

`stroke-dashoffset` анимировать при 60 fps — дорого; обновлять раз в секунду
с `transition: stroke-dashoffset 1s linear`.
