# T-0405 — Таймер

## 1. Цель

Таймер, которому можно доверять: точный после сна, слышимый, не мешающий,
с историей. Плюс режим помодоро как частный случай.

## 2. Функциональность

- Три режима: обратный отсчёт, секундомер, помодоро (25/5 с длинным перерывом).
- Пресеты: 1/3/5/10/25/45 мин; произвольное значение.
- Кольцо прогресса (SVG), цифры `t-display` tabular.
- По завершении: звук (тихий, выбор из 3), системное уведомление (право `notify`),
  мягкая пульсация виджета 3 с (не полноэкранная).
- Управление: старт/пауза/сброс, `Space` при фокусе, `S` с клавиатуры.
- Состояние переживает перезапуск: `endsAt` (абсолютное время), не «осталось».

## 3. Точность после сна

- Хранится `endsAt = now + duration`; тик только обновляет отображение
  (`remaining = endsAt - now`), поэтому пропуск тиков не влияет на точность.
- При `suspend` таймер продолжает «идти» по wall-clock (по умолчанию) —
  опция «останавливать на время сна».
- При пробуждении: если `endsAt` в прошлом — сработать один раз (не N раз),
  уведомление «Таймер завершился, пока система спала».
- Завершение фиксируется в БД (`state.completedAt`), чтобы не сработать дважды.

## 5. Критерии приёмки

- **AC-1** Отклонение от реального времени ≤ 100 мс за 60 минут.
- **AC-2** Сон 30 минут → одно срабатывание, корректное уведомление.
- **AC-3** Перезапуск приложения во время отсчёта → таймер продолжается.
- **AC-4** Звук воспроизводится, если устройство вывода занято (не падает).
- **AC-5** Помодоро: 4 цикла → длинный перерыв, счётчик циклов виден.
