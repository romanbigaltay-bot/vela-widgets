# ST-0401-01 — Реестр модулей

## Цель

Модули регистрируются единообразно, манифест валидируется на старте.

## Реализация

1. `shared/widgets/registry.ts`: `class WidgetRegistry { register(m); get(id); list() }`.
2. Валидация манифеста: обязательные поля, `id` в формате `namespace.kebab`,
   `apiVersion === 1`, размеры кратны 8, `defaultSize` входит в `sizes`.
3. Ошибка в манифесте — падение на этапе сборки (dev) и запись в лог (prod),
   модуль не регистрируется, остальные работают.
4. `registry.manifests()` → IPC `widget.manifest_list` при старте, кэш в Rust.
5. Дубликат `id` — ошибка сборки.

## Критерии приёмки

- AC-1 Модуль с невалидным манифестом не регистрируется и логируется.
- AC-2 Список манифестов в Rust совпадает с реестром (тест сравнения).
- AC-3 Дубликат `id` ловится тестом сборки.

## Тест-план

Юнит: 8 манифестов (валидные/невалидные), проверка результата регистрации.

## Риски

Динамическая загрузка модулей в v1 не поддерживается — не закладывать API,
который потом придётся выпиливать.
