# ST-0401-04 — Visibility-машина и пауза тикеров

## Цель

Ни один виджет не тратит CPU, когда его не видно.

## Реализация

1. `useVisibility(id)`: состояние из `IntersectionObserver` (в вьюпорте) +
   флагов `overlayOpen` (C активен) + `fullscreenApp` (из Rust) + `suspended`.
2. Машина: `visible → occluded → offscreen`, переходы идемпотентны.
3. `ClockService` подписчики получают паузу: при `offscreen` — тик не вызывается,
   при `occluded` — вызывается с `skipped: true` (виджет сам решает, накапливать
   ли пропуски).
4. При возврате в `visible` — один «догоняющий» вызов с фактическим временем
   (для часов), чтобы не показывать устаревшее значение.
5. Детект fullscreen-приложения: из Rust (`GetForegroundWindow` + сравнение с
   размером монитора), событие `system.foreground_fullscreen`.

## Критерии приёмки

- AC-1 Виджет за пределами вьюпорта: 0 вызовов тикера за 10 с.
- AC-2 Fullscreen-игра: все анимации виджетов стоят (0 fps).
- AC-3 Возврат в вьюпорт: часы показывают правильное время сразу (< 1 кадра).

## Тест-план

TC-0401-04 + ручной тест с fullscreen-видео.

## Риски

`IntersectionObserver` внутри трансформированного мира может давать неточные
границы → использовать вычисление пересечения по камере (ST-0301-03), а
`IntersectionObserver` только как страховку.
