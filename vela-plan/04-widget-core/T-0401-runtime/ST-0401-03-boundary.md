# ST-0401-03 — Изоляция ошибок

## Цель

Один сломанный модуль не должен стоить пользователю рабочего стола.

## Реализация

1. `WidgetBoundary`: классовый `ErrorBoundary` вокруг каждого экземпляра.
2. Плашка ошибки: иконка, «Модуль остановлен», код ошибки (короткий),
   кнопки «Перезапустить» / «Отключить». В плашке — тот же размер, что у виджета
   (раскладка не прыгает).
3. Счётчик падений: 3 падения за 5 минут → модуль автоматически отключается
   с тостом (защита от циклов).
4. `unhandledrejection` внутри виджета (по `ctx`-скоупу) также ловится.
5. В dev — полный стек в консоль; в prod — только код + запись в лог-буфер.

## Критерии приёмки

- AC-1 Искусственный `throw` → плашка, остальные виджеты живы.
- AC-2 «Перезапустить» восстанавливает модуль без перезагрузки страницы.
- AC-3 Три падения подряд → автоотключение с тостом.

## Тест-план

TC-0401-01.

## Риски

`ErrorBoundary` не ловит ошибки в асинхронных колбэках → обёртка промисов в
`ctx` и глобальный `unhandledrejection` с фильтром по стеку.
