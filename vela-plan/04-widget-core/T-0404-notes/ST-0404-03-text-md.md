# ST-0404-03 — Текст и markdown-lite

## Цель

Свободный текст с минимальным форматированием и полной безопасностью.

## Реализация

1. `TextEditor.tsx`: `textarea` (автовысота) в режиме редактирования,
   рендер — в режиме просмотра (клик → правка).
2. Парсер markdown-lite: `**bold**`, `*italic*`, `- list`, `[text](url)`,
   автоссылки. Никаких HTML-тегов.
3. Рендер — React-элементы, не `dangerouslySetInnerHTML` (гарантия от XSS).
4. Ссылки — `shell.openExternal` через IPC с проверкой схемы (`http/https` только).
5. Поиск: подсветка вхождений в режиме просмотра; поле поиска появляется по
   `Ctrl+F` внутри виджета.

## Критерии приёмки

- AC-1 `<img src=x onerror=alert(1)>` отображается как текст.
- AC-2 Открытие ссылки проходит через проверку схемы; `javascript:` блокируется.
- AC-3 Автовысота не даёт «прыжка» при вводе.

## Тест-план

TC-0404-03 (6 векторов XSS), тест ссылок (3 схемы).

## Риски

Парсер на каждый символ дорог → парсинг только в режиме просмотра, не при вводе.
