# ST-0404-02 — Чек-лист

## Цель

Ввод и отметка задач без трения: два действия — добавить и отметить.

## Реализация

1. `Checklist.tsx`: список с виртуализацией при > 40 пунктов (`react-window`-like).
2. `Enter` в поле ввода → новый пункт, фокус остаётся в поле.
3. Чекбокс — `data-no-drag`, кастомный (не нативный) с `role="checkbox"` и
   клавиатурой (`Space`).
4. Выполненные: `opacity .45` + зачёркивание; автоперенос вниз — опция
   (по умолчанию выключено, чтобы не «прыгало» под курсором).
5. Удаление — по `×` на hover, с отменой 5 с.
6. Сохранение — дебаунс 600 мс, принудительно на `blur`.

## Критерии приёмки

- AC-1 Добавление 50 пунктов подряд без потери фокуса.
- AC-2 Чекбокс не инициирует drag виджета.
- AC-3 Порядок сохраняется после перезапуска.

## Тест-план

TC-0404-02, TC-0404-04.

## Риски

Виртуализация + редактирование in-place конфликтуют → редактирование через
инлайн-инпут с явным `onBlur`, не contenteditable.
