# ST-0402-01 — Карточка

## Цель

Единая рамка, которая выглядит дорого и не мешает содержимому.

## Реализация

1. `WidgetCard`: `Glass` + заголовок (`t-label`, `--text-dim`) + `⋯` +
   зона содержимого (`overflow: hidden`, `border-radius: inherit`).
2. Заголовок — drag handle (`cursor: grab`), двойной клик — toggle компактного
   размера (если есть).
3. Ресайз: `useResize` с `pointer`-событиями, шаг 8, ограничения из манифеста,
   коммит на `pointerup`.
4. Меню `⋯`: `Menu` из ui-kit, пункты по контексту (без «Настроек», если у
   модуля нет `settingsSchema`).
5. Плашка ошибки занимает ровно тот же размер, что и содержимое.

## Критерии приёмки

- AC-1 Ресайз: минимальный размер соблюдается, шаг 8 px.
- AC-2 Меню закрывается по `Escape`, фокус возвращается на `⋯`.
- AC-3 Заголовок не перекрывает содержимое при высоте виджета < 80 px
  (заголовок скрывается автоматически).

## Тест-план

TC-0402-01 + визуальные скриншоты 4 размеров.

## Риски

`overflow: hidden` + стекло = обрезка blur по краям → blur-таргет берётся с
запасом 10 % (см. ST-0304-02).
