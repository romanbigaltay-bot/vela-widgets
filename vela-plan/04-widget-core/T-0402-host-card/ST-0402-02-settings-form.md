# ST-0402-02 — Автоформа настроек

## Цель

Модуль не пишет UI настроек: схема → форма.

## Реализация

1. `SchemaForm`: поддержка `string`, `number` (`min/max/step`), `boolean`,
   `enum`, `color`; `title`/`description` из схемы.
2. Валидация на вводе (не на сабмите) + серверная валидация при `settings_update`.
3. Изменения применяются вживую (оптимистично), откат при ошибке.
4. Поддержка `x-group` для группировки полей (доп. аннотация в схеме).
5. Кнопка «Сбросить» — значения по умолчанию из `default` в схеме.

## Критерии приёмки

- AC-1 Пять типов полей рендерятся и валидируются.
- AC-2 Невалидное значение не даёт сохранить и объясняет, почему.
- AC-3 Сброс возвращает значения из `default`.

## Тест-план

TC-0402-02: 5 схем, включая граничные (min=max, пустой enum).

## Риски

Цвет-поле в тёмной теме должно показывать контраст — использовать `--text`
для значения, не «как в пикере».
