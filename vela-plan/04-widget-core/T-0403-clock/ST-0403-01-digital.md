# ST-0403-01 — Цифровые часы

## Цель

Точное, стабильное по ширине время, читаемое на любом фоне.

## Реализация

1. `Clock.tsx`: два `<span>` (часы/минуты) + `:` + опциональные секунды.
2. Кэш `Intl.DateTimeFormat` по ключу `(locale, opts)` в модульном `Map`.
3. `useTick(1000)` из `ctx.clock`; при `occluded` — пауза, при возврате —
   принудительный ререндер с текущим временем.
4. Ширина: `font-variant-numeric: tabular-nums`, контейнер с `min-width` по
   макету, чтобы при смене 1→8 не дёргался layout.
5. Дата — `Intl` с `weekday: 'long', day: 'numeric', month: 'long'`, первая буква
   заглавная (локальная функция, не CSS).

## Критерии приёмки

- AC-1 Время ±1 с за 10 минут работы.
- AC-2 Нет смещения при смене всех цифр (тест на измерение ширины).
- AC-3 Дата корректна для ru/en.

## Тест-план

TC-0403-01, TC-0403-04.

## Риски

`Intl` в WebView2 может отличаться от Node в тестах → тестировать через реальный
браузерный прогон для локали.
