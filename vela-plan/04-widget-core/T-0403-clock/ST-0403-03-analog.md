# ST-0403-03 — Аналог и компакт

## Цель

Два альтернативных вида, не ломающих сетку.

## Реализация

1. Аналог: SVG 120×120, 12 штрихов (`--stroke`), две стрелки (`--text`),
   тонкая (1.5 px), без заливки круга; секундная — опция, `--accent`.
2. Поворот через `transform: rotate(deg)` на группах; обновление раз в секунду
   (без rAF).
3. Компакт: только время, `t-display` (32 px), дата скрыта, `min-size 120×64`.
4. Переключение вида — настройка `variant: 'digital'|'analog'|'compact'`.
5. Все три варианта используют один `useTick`, чтобы не плодить таймеры.

## Критерии приёмки

- AC-1 Аналог не мылится при `scale` 2.2 (проверка скриншотом).
- AC-2 Компакт при 120×64 не обрезает цифры.
- AC-3 Смена варианта не создаёт второй таймер.

## Тест-план

Визуальные скриншоты трёх вариантов на 3 масштабах.

## Риски

SVG с `transform` на группах может давать субпиксельный сдвиг стрелки —
`transform-box: fill-box; transform-origin: center`.
