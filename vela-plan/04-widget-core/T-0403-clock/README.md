# T-0403 — Часы

## 1. Цель

Первый модуль, доказывающий контракт. И одновременно — самый часто видимый
элемент интерфейса, поэтому к нему повышенные требования по типографике.

## 2. Функциональность

- Цифровые часы: часы/минуты крупно (`t-hero`, 44 px, tabular), секунды —
  мелко или точкой-пульсом (опция).
- Дата: «вторник, 22 октября» — локаль, без года (опция).
- Дополнительные часовые пояса до 3: компактные строки с городом и временем.
- Формат 12/24 ч, показывать ли секунды, показывать ли дату — из `settingsSchema`.
- Аналоговый вариант (опция): тонкие штрихи, без заливок, 2 стрелки.
- Клик — переключение компактного режима (только время).

## 3. Особенности реализации

- Тик — 1000 мс через `ctx.clock`, при `occluded` не обновляется, при возврате —
  догоняющий вызов.
- Секундная точка пульсирует CSS-анимацией 1 Гц, останавливается при
  `visibility !== visible` (иначе это вечный rAF).
- Форматирование через `Intl.DateTimeFormat` с кэшем инстансов (создание
  форматтера на каждый тик — дорого).
- Смена часового пояса системы подхватывается без перезапуска (сравнение
  `resolvedOptions().timeZone` раз в минуту).

## 5. Критерии приёмки

- **AC-1** Время совпадает с системным с точностью ±1 с после 10 минут работы.
- **AC-2** Смена часового пояса ОС подхватывается ≤ 60 с.
- **AC-3** Компактный режим не ломает вёрстку при 120×64.
- **AC-4** Тиков: 1 в секунду, не больше (счётчик в dev).
- **AC-5** Шрифт цифр — tabular, цифры не «пляшут» (визуальная проверка на записи).
