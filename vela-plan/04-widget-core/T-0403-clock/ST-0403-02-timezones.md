# ST-0403-02 — Часовые пояса

## Цель

До трёх дополнительных поясов, компактно и без путаницы.

## Реализация

1. Настройки: `zones: string[]` (IANA), максимум 3; `showDate`, `showSeconds`,
   `format: '12'|'24'`.
2. Строки поясов: город (короткое имя из карты) + время `HH:mm`, `t-body`/`--text-dim`.
3. Карта коротких имён для 30 популярных зон; для неизвестных — срез IANA после
   последнего `/` с заменой `_`.
4. Пересчёт при каждом тике (тот же, что часы) — без отдельных таймеров.
5. Смена системного пояса: раз в 60 с сравнение `Intl.DateTimeFormat().resolvedOptions().timeZone`.

## Критерии приёмки

- AC-1 Три пояса отображаются корректно, включая переход через полночь.
- AC-2 Смена пояса ОС подхватывается ≤ 60 с.
- AC-3 Пустой список поясов не оставляет пустого блока (секция скрыта).

## Тест-план

TC-0403-02 + тест на `Dst`-переход (фиксированная дата через инжект часов).

## Риски

Некорректная IANA-зона от пользователя → валидация при сохранении настроек.
