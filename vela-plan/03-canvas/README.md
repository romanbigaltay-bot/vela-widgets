# P3 — Бесконечный холст

**Цель этапа:** рабочая плоскость, на которой живут элементы: pan/zoom, сетка,
снап, выделение, режимы ввода, профили и честное стекло. Виджетов ещё нет —
на холсте лежат заглушки, но всё поведение настоящее.

**Оценка:** 9 дней. **Gate:** G3.

| ID | Задача | Приоритет | Дней | Владелец | Зависит от |
|---|---|---|---|---|---|
| T-0301 | Мир, вьюпорт, трансформации | P0 | 2.0 | ui | P2 |
| T-0302 | Модель раскладки и персистентность | P0 | 2.0 | rust+ui | T-0301 |
| T-0303 | Взаимодействие: drag, снап, выделение | P0 | 2.5 | ui | T-0302 |
| T-0304 | Стекло и blur mirror | P0 | 1.5 | ui | T-0301 |
| T-0305 | Профили и переключение сцен | P1 | 1.0 | rust+ui | T-0302 |

## Порядок

```
T-0301 ──► T-0302 ──┬──► T-0303 ──┐
        └──► T-0304 ──────────────┼──► G3
T-0302 ──► T-0305 ────────────────┘
```

T-0304 (стекло) можно делать параллельно с T-0303: они не пересекаются по коду,
кроме общего рендер-цикла (разделяется по слоям: стекло в `scene/glass`,
элементы в `canvas/elements`).

## Критерии выхода (G3)

- [ ] Pan/zoom колесом, drag, `Fit`, `Ctrl+0`; зум к курсору без дрейфа.
- [ ] Перетаскивание элемента: снап к сетке 8, направляющие, `Alt` — свободно, `Esc` — отмена.
- [ ] Мультивыделение рамкой, групповое перемещение, z-order.
- [ ] Раскладка сохраняется и восстанавливается, включая позиции после перезапуска.
- [ ] Стекло размывает содержимое сцены под панелью; стоимость ≤ 0.8 мс.
- [ ] Профили переключаются, элементы возвращаются на свои места.
- [ ] Виртуализация: 500 элементов за вьюпортом не рендерятся, fps не падает.
- [ ] Idle: 0 кадров в секунду при отсутствии изменений.

## Что НЕ входит

Реальные модули виджетов (P4), захват (P5), контент сцены (P6).
