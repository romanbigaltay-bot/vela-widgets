# ST-0305-02 — Переключение профиля

## Цель

Быстрый, без вспышек, с честным откатом при ошибке.

## Реализация

1. Оркестратор в Rust: `activate(id)` → валидация → `scene.pause` →
   отправка сцены в A → `layout.apply_visibility` в B → `scene.play` → ack.
2. UI: crossfade на сцене (400 мс) и на элементах (200 мс, `opacity + scale .97`);
   при `reduced-motion` — без анимации.
3. Откат: если сцена не смогла открыться — вернуть `previous_profile`,
   элементы вернуть, тост с причиной.
4. Профиль «Игра» ставит сцену на паузу (0 fps) и скрывает все виджеты,
   оставляя только хоткей-доступ.
5. Метрика `tookMs` в событии — для бенчмарка AC-1.

## Критерии приёмки

- AC-1 ≤ 450 мс до полной готовности (метрика в событии).
- AC-2 Нет белого кадра при переходе между фото и видео-сценой.
- AC-3 Ошибка сцены откатывает профиль, элементы возвращены.

## Тест-план

TC-0305-01, TC-0305-02, TC-0305-03.

## Риски

Одновременная смена сцены и раскладки даёт «двойную» нагрузку на кадр →
разнести по времени: сначала сцена (fade out), затем раскладка, затем fade in.
