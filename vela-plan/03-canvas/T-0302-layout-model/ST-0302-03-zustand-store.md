# ST-0302-03 — Стор раскладки

## Цель

UI-состояние, которое мгновенно реагирует на жест и синхронизируется с БД
без мигания.

## Реализация

1. `canvas/store.ts`: `elements: Map<ElementId, Element>`, `zOrder`, `camera`,
   `revision`, `selection`, `mode`.
2. Жест: `beginGesture()` (снимок исходных значений) → `updateFrame()` (только
   стор, 60 Гц) → `commitGesture()` (IPC `apply_patch`).
3. Оптимистичное обновление: `commitGesture` не ждёт БД; при ошибке — откат
   к снимку + тост.
4. Селекторы: `useElement(id)`, `useVisibleElements()` (мемоизация по
   `visibleIds` + `elements`).
5. Снапшот с сервера: `applySnapshot(snap)` — заменяет элементы с большей
   `revision`, не затирая активный жест (если жест идёт — отложить до коммита).

## Критерии приёмки

- AC-1 Перетаскивание не вызывает IPC до `pointerup`.
- AC-2 Ошибка IPC откатывает позицию визуально за ≤ 100 мс.
- AC-3 Приход снапшота во время жеста не «дёргает» элемент.

## Тест-план

Vitest: искусственная ошибка IPC → проверка откатa; снапшот во время жеста.

## Риски

`Map` в Zustand требует иммутабельных обновлений (новый Map) → иначе селекторы
не перерисуются; правило зафиксировано в тесте.
