# ST-0302-04 — Восстановление и orphaned

## Цель

Отключение монитора не должно «терять» виджеты — пользователь всегда может
их вернуть.

## Реализация

1. При старте: `monitors` из БД сверяются с `EnumDisplayMonitors`. Совпадение —
   по `(w,h,scale)` + порядку; при несовпадении — эвристика ближайшего по геометрии.
2. Элементы несуществующего монитора: `orphaned = true`, переносятся в
   каскад в правом нижнем углу основного монитора, `z` сортируется.
3. UI: зона `orphaned` визуально приглушена (opacity .55) + бейдж «с другого
   экрана»; перемещение снимает флаг.
4. Событие `window.monitors_changed` → пересчёт в UI без перезапуска.
5. Единица переноса: целиком профиль? Нет — по одному элементу, чтобы не
   сломать раскладку.

## Критерии приёмки

- AC-1 Отключение второго монитора → элементы видны, помечены, доступны.
- AC-2 Повторное подключение не дублирует элементы.
- AC-3 Раскладка основного монитора не сдвигается.

## Тест-план

TC-0302-04; ручной MS-06.

## Риски

Эвристика сопоставления мониторов может перепутать два одинаковых экрана →
приоритет primary + порядок, при равенстве — каскад в orphaned (безопаснее, чем
потеря).
