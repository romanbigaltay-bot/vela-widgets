# T-0301 — Мир и вьюпорт

## 1. Цель

Математическое ядро холста: мировые координаты, вьюпорт, зум к курсору, pan,
границы, сетка. Всё остальное (элементы, стекло) опирается на это ядро.

## 2. Модель

```ts
interface Camera { x: number; y: number; scale: number }   // x,y — смещение мира в экранных px
// экран = мир * scale + (x, y)
screenX = worldX * scale + cam.x
worldX  = (screenX - cam.x) / scale
```

- Диапазон `scale`: 0.35 … 2.2, шаг зума — экспоненциальный (wheel * 0.0016).
- Зум к курсору: `cam.x = mx - (mx - cam.x) * (next / scale)` — та же формула,
  что в прототипе, она проверена.
- Камера — часть `layoutStore`, но изменения во время жеста не пишутся в БД
  (только по завершении, дебаунс 250 мс).
- Каждый монитор — свой вьюпорт; камеры независимы, но могут быть
  синхронизированы опцией `settings.canvas.sync_cameras`.

## 3. Виртуализация

- Рендерим только элементы, чей bounding box пересекает вьюпорт, расширенный на
  200 px (запас на анимацию входа).
- Список видимых пересчитывается по `camera` с троттлингом: не чаще 1 раза на
  кадр, через `requestAnimationFrame`.
- Для 500+ элементов — spatial hash (сетка 512×512 мировых px).

## 4. Рендер-цикл

```
нужен кадр? ──нет──► спим (0 fps)
   │да
   ├─ обновить камеру (если жест)
   ├─ пересчитать видимые
   ├─ отрисовать элементы (transform, не layout)
   └─ отрисовать стекло (только изменившиеся панели)
```

Правило: любое изменение свойств, влияющее на layout (ширина панели), ставит
флаг `dirtyLayout` и пересчитывает только затронутые элементы.

## 6. Критерии приёмки

- **AC-1** Зум к курсору: точка под курсором не смещается (тест на 20 шагов зума).
- **AC-2** Pan мышью и `Space+drag`; `Fit` вписывает все элементы с отступом 80 px.
- **AC-3** 500 элементов: fps ≥ 55 при pan, CPU ≤ 12 %.
- **AC-4** Idle: счётчик кадров = 0 за 10 с.
- **AC-5** Сетка визуально совпадает с мировыми линиями при любом масштабе
  (не «плывёт»), исчезает при `scale < 0.5` (иначе муар).
- **AC-6** Камера переживает перезапуск (сохранение последней позиции).

## 8. Риски

- R-08 (дрожание на 144 Гц) — только `transform`, `will-change: transform`
  на контейнере мира, никаких `left/top` в горячем пути.
- Дробные пиксели при зуме дают мыло на тексте → `text-rendering: geometricPrecision`
  и снап позиций элементов к 0.5 px на экране при `scale ≥ 1`.
