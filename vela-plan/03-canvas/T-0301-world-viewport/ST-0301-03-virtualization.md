# ST-0301-03 — Виртуализация

## Цель

Холст с сотнями элементов остаётся плавным; за вьюпортом ничего не рендерится.

## Реализация

1. `shared/lib/spatialHash.ts`: сетка 512×512 мировых px, `insert`, `remove`,
   `query(rect)`.
2. `canvas/store.ts`: `visibleIds` пересчитывается по `camera` + `viewport` +
   запас 200 px; сравнение с предыдущим набором — при изменении коммит в стор.
3. Элементы вне `visibleIds` не монтируются (не «скрываются»), но их состояние
   сохраняется в сторе (позиция, настройки).
4. Счётчик `renderedCount` для бенчмарка и для индикатора в dev-режиме.
5. Пересчёт — не чаще одного раза за кадр; при `pan` — на каждом кадре.

## Критерии приёмки

- AC-1 500 элементов: смонтировано в DOM ≤ 40 в вьюпорте 1600×950.
- AC-2 Перемещение камеры не «теряет» элементы (нет мигания при въезде).
- AC-3 Список видимых пересчитывается ≤ 1.5 мс для 500 элементов.

## Тест-план

Бенч-тест: засеять 500 элементов, измерить `visibleIds` и смонтированные узлы.

## Риски

Монтирование/размонтирование при быстром pan дёргает layout → использовать
`content-visibility: auto` для карточек и избегать тяжёлых `useEffect` в mount.
