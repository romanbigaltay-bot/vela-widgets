# ST-0303-02 — Снап и направляющие

## Цель

Элементы выравниваются «сами», но пользователь всегда может поставить точно.

## Реализация

1. `snap.ts`: `snapToGrid(v, step=8, threshold=6)`, `snapToEdges(rect, others, threshold)`
   — по 6 линиям (3 вертикали × 2 стороны + центры).
2. Приоритет: направляющая к соседу > сетка; при равном расстоянии — сетка.
3. Направляющие рисуются тонкой линией `1px` цветом `--accent` opacity .35,
   живут только во время жеста (отдельный слой canvas, не DOM).
4. `Alt` — полное отключение и снапа, и направляющих (проверяется вживую).
5. Расстояние до соседа показывается числом в чипах (только если < 64 px) —
   опция `settings.canvas.show_measurements`.
6. Снап по bounding box группы при групповом перетаскивании.

## Критерии приёмки

- AC-1 Порог соблюдается: 6 px — липнет, 8 px — нет (±0.5 px из-за DPR).
- AC-2 Направляющая появляется/исчезает без мерцания.
- AC-3 `Alt` мгновенно отключает снап (без задержки).
- AC-4 Работает корректно при `scale` 0.35 и 2.2.

## Тест-план

TC-0303-01: таблица из 30 кейсов (позиция, размеры соседа, ожидаемый результат).

## Риски

При большом числе соседей (>50) перебор даёт просадку → ограничить поиск
радиусом 400 мировых px через spatial hash из ST-0301-03.
