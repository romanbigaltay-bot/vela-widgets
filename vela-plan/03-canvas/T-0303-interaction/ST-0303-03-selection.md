# ST-0303-03 — Выделение

## Цель

Массовые операции без «прыгающих» элементов.

## Реализация

1. Рамка на пустом месте (`pointerdown` без элемента) → прямоугольник в мировых
   координатах → пересечение с visible-элементами (через spatial hash).
2. `Ctrl+клик` — toggle; клик по пустому месту без движения — снять выделение.
3. Групповой drag: сохраняем `Map<id, frame>` в `beginGesture`, двигаем все
   на одну дельту; снап по групповому bbox.
4. `Delete` — удаление с тостом «Удалено N · Отменить», 5 с на отмену
   (soft delete в сторе → реальное удаление по таймауту или при другом действии).
5. `Ctrl+A` — все видимые; `Tab` — фокус по порядку `z`, обводка focus-visible.
6. Визуал: выделенный — 1 px `--accent` + мягкое свечение; группа — общий bbox
   с углами.

## Критерии приёмки

- AC-1 Рамка на 200 элементах работает без просадки (< 8 мс на пересчёт).
- AC-2 Групповой drag сохраняет относительные позиции (тест на 20 элементах).
- AC-3 Отмена удаления возвращает элементы с их `z` и `settings`.
- AC-4 `Tab` не уводит фокус в скрытые (вне вьюпорта) элементы.

## Тест-план

TC-0303-03; тест на отмену удаления; клавиатурный e2e.

## Риски

Soft delete и синхронизация с БД могут рассинхронизироваться при крэше →
удаление фиксируется в БД сразу, отмена — обратным upsert (надёжнее, чем
отложенное удаление).
