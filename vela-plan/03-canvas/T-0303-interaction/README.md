# T-0303 — Взаимодействие

## 1. Цель

Ощущение «прямого манипулирования»: элемент следует за курсором без задержки,
прилипает к сетке и соседям, выделяется рамкой, отменяется по `Esc`.

## 2. Правила перетаскивания

| Правило | Детали |
|---|---|
| Снап к сетке | шаг 8 мировых px, порог 6 px, `Alt` — отключить |
| Направляющие | при совпадении края/центра с другим элементом — линия + подсветка края |
| Позиция | `transform: translate3d`, никогда `left/top` |
| Порог начала жеста | 3 px, иначе клик остаётся кликом |
| Отмена | `Esc` во время жеста → возврат к исходной позиции |
| Курсор | `grab` / `grabbing` в `edit`, обычный в `locked` |
| Курсор вне экрана | `pointercancel` → отмена, не «залипание» |

## 3. Выделение

- Клик — один элемент; `Ctrl/Cmd+клик` — добавить/убрать; рамка по пустому
  месту — пересечение.
- Групповое перемещение сохраняет относительные позиции; снап считается по
  bounding box группы.
- `Delete` — удалить с подтверждением (если элементов > 1) и возможностью
  отмены 5 с.
- `Ctrl+A` — все видимые; `Tab`/`Shift+Tab` — циклический фокус по элементам.

## 4. Z-order

- `Ctrl+]` / `Ctrl+[` — выше/ниже; `Ctrl+Shift+]` — на самый верх.
- Авто: клик по элементу поднимает его наверх (опция, по умолчанию выключена,
  чтобы не менять раскладку неожиданно).
- `z` хранится целым; при переполнении — нормализация (перенумерация с шагом 10).

## 6. Критерии приёмки

- **AC-1** Задержка «курсор → элемент» ≤ 1 кадр (16 мс), без дрожания на 60/144 Гц.
- **AC-2** Снап срабатывает при попадании в 6 px, не срабатывает на 8 px.
- **AC-3** `Alt` полностью отключает снап и направляющие.
- **AC-4** `Esc` во время жеста возвращает исходную позицию без обращения к БД.
- **AC-5** Рамка выделяет только пересечённые элементы; с `Ctrl` — добавляет.
- **AC-6** Групповой drag не «разъезжается» (относительные расстояния сохранены).
- **AC-7** Позиция после перезапуска совпадает с финальной экранной.

## 8. Риски

- R-08: дрожание на 144 Гц — только `translate3d` + `will-change`, проверить
  на реальном 144 Гц мониторе.
- Снап к сетке при `scale ≠ 1` даёт «половинки» — снап считается в мировых
  координатах, а не в экранных.
