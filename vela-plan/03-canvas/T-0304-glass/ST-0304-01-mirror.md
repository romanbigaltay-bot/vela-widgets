# ST-0304-01 — Blur mirror

## Цель

Дешёвый источник «того, что под панелью», без чтения текстуры из другого окна.

## Реализация

1. `scene/mirror.ts`: `MirrorCanvas` — `OffscreenCanvas` 0.25× вьюпорта.
2. Сцена A публикует `SceneDigest` (декларативное описание слоёв, без пикселей):
   `[{type:'gradient', stops, angle}, {type:'image', src, rect, fit}, {type:'video', frameBitmap?}]`.
3. B строит mirror из `SceneDigest` (drawImage/gradients) — стоимость < 0.5 мс
   на 0.25×.
4. Для видео: A раз в 250 мс присылает `ImageBitmap` текущего кадра (transferable).
5. `mirrorRevision` инкрементируется при каждом обновлении.
6. Частота обновления: управляется подписчиками (есть ли стеклянные панели).

## Критерии приёмки

- AC-1 Средний цвет mirror совпадает со средним цветом сцены ±5 % (по 9 зонам).
- AC-2 Стоимость построения mirror ≤ 0.5 мс.
- AC-3 При отсутствии панелей обновлений нет (0 fps).

## Тест-план

Сравнение цветов по зонам (скриншот сцены vs mirror, усреднение).

## Риски

`ImageBitmap` требует `transferControlToOffscreen` и аккуратной передачи между
окнами — при неудаче фолбэк: видео в mirror статично (кадр при смене сцены).
