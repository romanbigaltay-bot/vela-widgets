# T-0304 — Стекло

## 1. Цель

Честное размытие содержимого сцены под панелью, стоимость ≤ 0.8 мс на панель
400×300, с деградацией в матовое стекло, когда сцена недоступна.

## 2. Механика

1. **Blur mirror** (ADR-0003): поверхность B держит offscreen `canvas` 0.25× от
   размера вьюпорта, на который сцена A «публикует» упрощённую композицию
   (те же слои: цвета, градиенты, изображение/кадр видео). Публикация — через
   `postMessage` от A к B (или через Rust-релей) с частотой:
   - 30 fps пока на экране есть стеклянная панель,
   - 4 fps если сцена статична,
   - 0 fps если панелей нет.
2. Для каждой стеклянной панели: вырезаем область из mirror (с учётом камеры),
   прогоняем `filter: blur(28px) saturate(1.4)` один раз в offscreen-таргет,
   кэшируем по ключу `(rect, mirrorRevision)`.
3. Наложение: `background-image` панели = закэшированный blur-таргет +
   `--glass-tint` + шум 3 % + верхняя светлая грань 1 px.
4. Панели не пересчитываются каждый кадр — только при изменении `rect` или
   `mirrorRevision` (не чаще 4 раз в секунду).

## 3. Деградации

| Условие | Поведение |
|---|---|
| Сцена отключена / `pass`-режим с игрой | панель матовая (`--panel` 0.86), без blur |
| `power_state.saver` | то же + без шума |
| Нет WebGL2 | матовая |
| Панелей > 4 | 5-я и далее матовые (R-13) |
| Оверлей C активен | blur заморожен (нет обновления mirror) |

## 5. Критерии приёмки

- **AC-1** Под панелью видно размытое содержимое сцены, совпадающее по композиции.
- **AC-2** Стоимость одной панели 400×300 ≤ 0.8 мс (микробенч, 300 кадров).
- **AC-3** Сцена отключена → панели матовые, без «грязной» полупрозрачности.
- **AC-4** При 0 стеклянных панелей mirror не обновляется (0 fps).
- **AC-5** Светлая тема: стекло светлое, не серое; тёмная — глубокое, не мутное.
- **AC-6** Текст поверх стекла сохраняет контраст ≥ 4.5:1 (замер по пикселям).

## 7. Риски

- R-06 (расхождение mirror и сцены) — mirror строится из того же декларативного
  описания, что и сцена; тест сравнивает средние цвета областей.
- R-13 (много панелей) — лимит 4 стеклянных, остальные матовые, с подсказкой.
