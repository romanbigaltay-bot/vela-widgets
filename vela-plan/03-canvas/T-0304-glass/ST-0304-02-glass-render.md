# ST-0304-02 — Рендер стекла

## Цель

Стекло, которое выглядит дорого и не «съедает» контент по контрасту.

## Реализация

1. `glass/compose.ts`: для панели `rect` — вырезать из mirror область с запасом
   10 % (чтобы blur не тянул край), `ctx.filter = 'blur(14px) saturate(1.4)'`
   (14 px в 0.25× ≈ 28 px экранных), отрисовать в кэш-таргет.
2. Слои композита: blur-таргет → `--glass-tint` (rgba 4–8 %) → шум 3 %
   (`noise.png` 64×64 tile, `mix-blend-mode: overlay`, `opacity .035`) →
   верхняя грань `linear-gradient(rgba(255,255,255,.08), transparent 40%)` →
   тонкая рамка `1px --stroke` + внутренняя светлая `1px rgba(255,255,255,.06)`.
3. Кэш: `Map<key, ImageBitmap>`, ключ = `rect|mirrorRevision|theme`;
   LRU на 12 записей, освобождение через `close()`.
4. Тема влияет на tint и шум (в светлой — светлее, шум меньше).
5. Панели с `interactive` дополнительно получают `--glow` на hover (внешняя
   тень 0 0 24px accent/12 %), на статике — нет.

## Критерии приёмки

- AC-1 Визуально: под стеклом читается форма сцены (не однотонная плашка).
- AC-2 Контраст текста на стекле ≥ 4.5:1 в обеих темах (пиксельный замер).
- AC-3 Прозрачность краёв чистая, без «грязной» рамки от blur.
- AC-4 Нет артефактов на границе панели при масштабе 1.5×.

## Тест-план

TC-0304-02, TC-0304-03.

## Риски

`ctx.filter` в WebView2 может быть медленным на iGPU → альтернатива: собственный
шейдер (двухпроходный box blur) в WebGL; выбор по бенчмарку на целевом железе.
