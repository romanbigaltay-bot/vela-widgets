# ST-0201-02 — Трей и меню

## Цель

Управление приложением без открытия настроек: сцена, UI, режимы, профили, выход.

## Реализация

1. `TrayIconBuilder` с двумя иконками (light/dark) — выбор по теме панели задач
   (`HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize\SystemUsesLightTheme`).
2. Меню: `Показать сцену ✓`, `Показать виджеты ✓`, подменю `Режим` (edit/locked/pass),
   подменю `Профиль` (динамически из БД), `Настройки…`, `Выход`.
3. Клик по иконке — toggle видимости UI.
4. Состояние меню синхронизируется из `SurfaceManager` и `layout` события;
   чекбоксы не живут отдельной правдой.
5. Меню пересобирается при изменении профилей (событие `profile.changed`).

## Критерии приёмки

- AC-1 Пункты меню активны только когда имеют смысл (нет профилей → подменю пустое).
- AC-2 Клик по иконке скрывает/показывает UI за ≤ 100 мс.
- AC-3 Выход корректно завершает все поверхности и поток cron (после P7).

## Тест-план

Ручной сценарий + интеграционный тест на изменение состояния меню после
программного переключения режима.

## Риски

Меню в Tauri 2 обновляется только пересозданием → частая пересборка даёт
мигание; батчить изменения через 50 мс.
