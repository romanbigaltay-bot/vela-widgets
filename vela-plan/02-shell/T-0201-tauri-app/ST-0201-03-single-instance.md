# ST-0201-03 — Single instance и жизненный цикл

## Цель

Один процесс, осмысленная реакция на второй запуск и на закрытие окон.

## Реализация

1. Плагин `single-instance` с колбэком: развернуть UI, показать тост «Vela уже
   запущена», передать argv первому экземпляру.
2. argv-обработка: `--settings` открывает настройки, `--no-scene` стартует
   без сцены (отладка), `--safe-mode` — без WorkerW.
3. `on_window_event(CloseRequested)` для B: `prevent_close()`, скрыть, тост.
4. Корректное завершение: `flush` БД, остановка планировщика, `destroy` всех
   поверхностей, `app.exit(0)`.
5. Глобальный хоткей `Ctrl+Alt+Q` — выход с подтверждением в тосте (5 с на отмену).

## Критерии приёмки

- AC-1 Второй экземпляр не создаёт окон и завершается за ≤ 300 мс.
- AC-2 Alt+F4 не убивает процесс, состояние БД не теряется.
- AC-3 `--safe-mode` позволяет запуститься при сломанном WorkerW.

## Тест-план

CLI-тест: запустить дважды, проверить единственный процесс; проверить коды
выхода.

## Риски

`--safe-mode` забывают обновлять при добавлении фич → он должен быть в матрице
тестов этапа.
