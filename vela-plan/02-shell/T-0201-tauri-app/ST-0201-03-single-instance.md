# ST-0201-03 — Single instance и жизненный цикл

## 0. Фактическое состояние (2026-11-15)

Реализовано в `apps/desktop/src/app.rs`, `cli.rs` и `tray.rs`:

- `tauri-plugin-single-instance` подключён первым плагином. Второй процесс
  передаёт argv первому и завершается с кодом 0; первый вызывает
  `tray::show_ui` (если поверхность ещё не создана — запоминает
  `pending_show`).
- `--settings`, `--no-scene`, `--safe-mode` разбираются в `CliOptions` и
  логируются. Потребителей пока нет: настройки — T-0204, сцена/WorkerW —
  T-0202.
- `CloseRequested` для окна с меткой `vela-ui-*`: `prevent_close()` и
  скрытие поверхности. Alt+F4 не завершает процесс.
- «Выход» из трея: `quitting = true`, `app.exit(0)`; `RunEvent::Exit`
  вызывает `destroy_all` и `Prepared::shutdown` (WAL сбрасывается).
- Коды выхода: 0 — штатно, 1 — ошибка инициализации, 2 — БД новее бинаря.

Подтверждение AC:

| AC | Доказательство |
|---|---|
| AC-1 | второй экземпляр: 44.7–45.4 мс, exit 0; число окон `Tauri Window` у первого остаётся 1 |
| AC-2 | реальный Alt+F4 через `SendKeys`: окно скрылось, процесс жив, ex-style `0x08000190` не изменился |
| AC-3 | флаг `--safe-mode` разобран и сохранён; содержательная проверка на сломанном WorkerW невозможна до T-0202 — перенесена туда |

Отклонения: тост «Vela уже запущена» отложен; `Ctrl+Alt+Q` — T-0205;
`--settings`/`--no-scene` пока только логируются.

Статус — `done` (2026-11-15).

## Цель

Один процесс, осмысленная реакция на второй запуск и на закрытие окон.

## Реализация

1. Плагин `single-instance` с колбэком: развернуть UI, показать тост «Vela уже
   запущена», передать argv первому экземпляру.
2. argv-обработка: `--settings` открывает настройки, `--no-scene` стартует
   без сцены (отладка), `--safe-mode` — без WorkerW.
3. `on_window_event(CloseRequested)` для B: `prevent_close()`, скрыть, тост.
4. Корректное завершение: `flush` БД, остановка планировщика, `destroy` всех
   поверхностей, `app.exit(0)`.
5. Глобальный хоткей `Ctrl+Alt+Q` — выход с подтверждением в тосте (5 с на отмену).

## Критерии приёмки

- AC-1 Второй экземпляр не создаёт окон и завершается за ≤ 300 мс.
- AC-2 Alt+F4 не убивает процесс, состояние БД не теряется.
- AC-3 `--safe-mode` позволяет запуститься при сломанном WorkerW.

## Тест-план

CLI-тест: запустить дважды, проверить единственный процесс; проверить коды
выхода.

## Риски

`--safe-mode` забывают обновлять при добавлении фич → он должен быть в матрице
тестов этапа.
