# P2 — Оболочка: окна и поверхности

**Цель этапа:** три поверхности живут, сцена лежит под иконками, UI над ними,
оверлей по вызову; приложение живёт в трее, стартует с Windows по опции,
переживает перезапуск Explorer и смену разрешения.

**Оценка:** 8 дней. **Gate:** G2.

| ID | Задача | Приоритет | Дней | Владелец | Зависит от |
|---|---|---|---|---|---|
| T-0201 | Приложение Tauri: трей, один экземпляр, окна-скелеты | P0 | 1.5 | rust | P1 |
| T-0202 | Поверхность A: WorkerW и life-cycle сцены | P0 | 2.0 | rust | T-0201 |
| T-0203 | Поверхность B: прозрачный UI, no-activate, режимы ввода | P0 | 2.0 | rust | T-0201 |
| T-0204 | Автозапуск, питание, восстановление после Explorer | P0 | 1.5 | rust | T-0202 |
| T-0205 | Поверхность C: оверлей и глобальные хоткеи | P1 | 1.0 | rust | T-0203 |

## Порядок

```
T-0201 ──┬──► T-0202 ──► T-0204 ──┐
         └──► T-0203 ──► T-0205 ──┴──► G2
```

T-0202 и T-0203 можно вести параллельно: они трогают разные окна, но обе
пользуются модулем `VelaWindow` из T-0201.

## Критерии выхода (G2)

- [ ] При запуске: сцена под иконками, UI над иконками, ничего не мигает.
- [ ] Трей: показать/скрыть сцену, показать/скрыть UI, режимы, настройки, выход.
- [ ] Второй запуск не создаёт второе приложение, а активирует первое.
- [ ] Автозапуск: включение/выключение из настроек, проверено после перезагрузки.
- [ ] `taskkill /f /im explorer.exe` + запуск Explorer → всё восстановилось за ≤ 2 с.
- [ ] Смена разрешения/DPI не ломает окна (проверено на 125 % → 100 %).
- [ ] Закрытие UI (Alt+F4) не убивает приложение — только скрывает.
- [ ] RDP-сессия: приложение работает, сцена деградирует с предупреждением.

## Что НЕ входит

Холст, виджеты, стекло, сцена как контент. Поверхности пустые (цвет-заглушка),
но с правильным поведением окон.
