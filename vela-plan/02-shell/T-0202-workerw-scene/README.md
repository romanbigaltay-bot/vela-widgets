# T-0202 — Поверхность A (сцена)

## 1. Цель

Окно со сценой, вставленное в иерархию рабочего стола под иконками, с
устойчивостью к перезапуску Explorer и смене конфигурации мониторов.

## 2. Механика WorkerW

1. Найти окно `Progman`; послать `0x052C` (`WM_SPAWN_WORKER`) дважды — это
   заставляет Explorer создать слой `WorkerW` с `SHELLDLL_DefView` в одном из них.
2. Перебором `EnumWindows` найти тот `WorkerW`, у которого **нет** дочернего
   `SHELLDLL_DefView` — это и есть слой над обоями.
3. `SetParent(hwnd, workerw)`, затем `SetWindowPos` в границы монитора,
   `ShowWindow(SW_SHOWNOACTIVATE)`.
4. Стили: `WS_CHILD` **не** ставим (иначе WebView2 теряет ввод и DPI),
   `WS_EX_NOACTIVATE | WS_EX_TRANSPARENT | WS_EX_TOOLWINDOW`.

**Почему не `WS_CHILD`:** с `WS_CHILD` окно теряет `WM_DPICHANGED` и часть
композиции WebView2 работает некорректно. `SetParent` без `WS_CHILD` даёт
нужное z-положение без этих потерь — проверено на 23H2/24H2.

## 3. Устойчивость

- Регистрируем `TaskbarCreated` — сообщение приходит после перезапуска Explorer.
  Реакция: пересоздать родителя (найти WorkerW заново) и переустановить parent у
  всех поверхностей, не пересоздавая WebView2 (сохранение состояния сцены).
- `WM_DISPLAYCHANGE`, `WM_DPICHANGED` — пересчёт геометрии всех поверхностей.
- Таймаут ожидания WorkerW: 3 с; не нашли — фолбэк-режим (обычное нижнее окно
  `HWND_BOTTOM` + баннер «иконки будут перекрыты»).

## 4. Фолбэк-политика

| Условие | Поведение |
|---|---|
| WorkerW не найден | окно внизу z-порядка, иконки перекрыты, предупреждение в трее |
| RDP-сессия | сцена отключена, статичный цвет, тост |
| WorkerW пропал на ходу | пересоздание до 3 раз, потом фолбэк |
| Пользователь выключил сцену | окно существует, но скрыто и не рендерит |

## 6. Критерии приёмки

- **AC-1** Сцена видна под иконками, иконки отвечают на клики, сцена — нет.
- **AC-2** Explorer перезапущен → сцена вернулась за ≤ 2 с без перезапуска приложения.
- **AC-3** Второй монитор подключён/отключён → геометрия верная, без растяжения.
- **AC-4** Смена масштаба 100 % → 150 % → текст сцены не мыльный (devicePixelRatio обновлён).
- **AC-5** `--safe-mode` и отсутствие WorkerW дают работающее приложение с предупреждением.
- **AC-6** В RDP приложение работает, сцена отключена, есть тост.

## 8. Риски

- R-01 (WorkerW ломается) — модуль изолирован, фича-флаг, три версии Windows в CI-матрице.
- R-02 (Explorer restart) — `TaskbarCreated` + тест TC-0202-02 на каждом гейте.
- Антивирусы реагируют на `SetParent` к системным окнам — код без инъекций,
  только Win32 API, подпись бинаря обязательна (P8).
