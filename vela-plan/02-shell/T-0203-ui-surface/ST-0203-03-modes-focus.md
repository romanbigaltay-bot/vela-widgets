# ST-0203-03 — Режимы и фокус

## Цель

Три режима переключаются мгновенно и без побочных эффектов; ввод текста
работает, когда нужен, и не блокирует чужие окна, когда не нужен.

## Реализация

1. `window.set_mode { mode }` — валидация, применение стилей и флага хит-теста,
   широковещательное событие `window.mode_changed` во все B.
2. `request_keyboard { element_id }` — снимает `WS_EX_NOACTIVATE`,
   `SetForegroundWindow`, `SetFocus`; сохраняет предыдущий foreground HWND.
3. `release_keyboard` — возвращает `WS_EX_NOACTIVATE` и фокус предыдущему окну
   (`SetForegroundWindow(prev)`), вызывается по `Escape` и по потере фокуса.
4. Хоткеи режимов (глобальные, зарегистрированы в T-0205): `Ctrl+Alt+E/L/P`.
5. Синхронизация: смена режима из трея, хоткея или UI — всегда через одну
   команду, чтобы не было рассинхрона (правило «один владелец»).

## Критерии приёмки

- AC-1 100 переключений подряд: нет мерцания, нет утечки хендлов.
- AC-2 Клик в поле заметки в `locked` даёт фокус и позволяет печатать.
- AC-3 `Escape` возвращает фокус приложению, которое было активным.
- AC-4 Хоткей меняет режим и в трее, и в UI, без расхождений.

## Тест-план

TC-0203-02, TC-0203-03; замер времени переключения (≤ 30 мс).

## Риски

`SetForegroundWindow` может быть запрещён Windows (антифокус-стилинг) —
использовать `AttachThreadInput` в случае отказа; логировать неуспех.
