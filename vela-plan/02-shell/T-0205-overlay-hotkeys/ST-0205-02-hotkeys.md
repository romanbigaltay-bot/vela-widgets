# ST-0205-02 — Глобальные хоткеи

## Цель

Набор хоткеев, которые не ломают систему, настраиваются и честно сообщают
о конфликтах.

## Реализация

1. Реестр `HotkeyRegistry` с дефолтами: `Ctrl+Alt+K`, `Ctrl+Alt+E/L/P`,
   `Ctrl+Alt+T`, `Ctrl+Alt+S`, `Ctrl+Alt+Q`.
2. `RegisterHotKey` через Tauri global-shortcut; при
   `ERROR_HOTKEY_ALREADY_REGISTERED` — `VelaError{code: Busy, message: "хоткей занят"}`.
3. Регистрация при старте из БД (`settings.hotkeys`), изменение — через настройки
   с валидацией: запрещены комбинации без модификатора, `Win`-комбинации только
   с предупреждением.
4. Отключение хоткея, если приложение в `pass`-режиме и пользователь так решил
   (`settings.hotkeys.active_in_pass = false`).
5. Список активных хоткеев виден в настройках и в трее (для диагностики
   «почему не работает»).

## Критерии приёмки

- AC-1 Занятый хоткей не регистрируется, остальные продолжают работать.
- AC-2 Смена хоткея применяется без перезапуска.
- AC-3 В настройках видно, какой хоткей активен и почему не сработал
  (последняя ошибка регистрации).

## Тест-план

TC-0205-02 + ручной тест с занятием комбинации другим приложением.

## Риски

Некоторые игры ставят LL-хуки и не пропускают `RegisterHotKey` в exclusive
fullscreen — документируется как известное ограничение с обходом (окно в окне).
