# ST-0204-01 — Автозапуск

## Цель

Надёжный автозапуск без прав администратора, с проверкой результата.

## Реализация

1. `autostart::enable()` — `RegSetValueExW` в `HKCU\...\Run`,
   значение `Vela` = `"C:\...\Vela.exe" --autostart`.
2. `autostart::disable()` — `RegDeleteValueW`, отсутствие значения не ошибка.
3. `autostart::is_enabled()` — читает ключ и сверяет путь с текущим `exe`.
4. При старте с `--autostart` — задержка 5 с (`tokio::time::sleep`) до создания
   поверхностей; лог `autostart: delayed start`.
5. При обновлении приложения — перезапись ключа с новым путём (в P8).
6. IPC: `app.autostart_get/set` + событие `app.autostart_changed`.

## Критерии приёмки

- AC-1 Значение в реестре появляется и исчезает корректно.
- AC-2 `is_enabled` возвращает `false`, если путь в ключе не совпадает с текущим.
- AC-3 Отказ доступа (`ERROR_ACCESS_DENIED`) даёт понятную ошибку с кодом.

## Тест-план

Интеграционный тест на реальном реестре с очисткой в `Drop` (пропуск в CI без
Windows).

## Риски

Тест может оставить мусор в реестре разработчика → обязательная очистка
и уникальное имя значения в тестах (`VelaTest`).
