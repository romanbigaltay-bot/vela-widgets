# 08 — Стиль кода

## Rust

- Edition 2021, `rustfmt` с `max_width = 100`, `clippy -D warnings` в CI.
- Крейты: `vela-core` (домен, БД), `vela-platform` (Win32/окна/захват),
  `vela-cron`, `vela-ipc` (типы + генерация TS), `vela` (бинарь, команды Tauri).
- Имена: `snake_case` функции/модули, `CamelCase` типы, `SCREAMING_SNAKE` константы.
- Ошибки: `thiserror` для домена, `anyhow` на границе. Никаких `unwrap()` в
  рантайме — только `expect("invariant: ...")` с объяснением инварианта.
- `unsafe`: каждый блок с комментарием `// SAFETY:` — что гарантирует корректность.
- Потоки: явные имена (`thread::Builder::new().name("cron")`), паника в потоке
  не должна убивать процесс — `catch_unwind` на границах потоков.

## TypeScript / React

- Строгий `tsconfig`: `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`.
- Компоненты — функция + `function` объявление, не `const`-стрелки, для читаемых стеков.
- Состояние: Zustand-стор на домен (`layoutStore`, `uiStore`, `sceneStore`),
  селекторы мемоизированы, никакого контекста для часто меняющихся данных.
- Стили: CSS-переменные + CSS-modules; Tailwind не используем (нужен полный
  контроль над токенами и стеклом, а не утилитарная скорость).
- Числа в интерфейсе — всегда `font-variant-numeric: tabular-nums`.
- Никаких магических цветов в компонентах: только `var(--...)` из токенов.

## CSS / дизайн-система

- Токены: `--bg`, `--panel`, `--stroke`, `--text`, `--text-dim`, `--text-faint`,
  `--accent`, `--shadow`, `--inner`, `--blur`, `--radius-*`, `--space-*`.
- Два набора токенов: `[data-theme="dark"]`, `[data-theme="light"]`. Светлая тема
  не инвертируется автоматически — значения подбираются вручную.
- Шкала типографики: 10.5 / 11.5 / 13 / 15 / 20 / 32 / 44. Никаких других размеров.
- Отступы: кратны 4, сетка элементов 8. Радиусы: 4 / 10 / 16 / 999.
- Тени — двухслойные, свет — только на `hover/active/focus`.
- Стекло — только `.glass`. Запрещено вкладывать `.glass` в `.glass`.
- Анимации: 120 мс вход, 200 мс переход, easing `cubic-bezier(.2,.8,.2,1)`.
  Всё, что дольше 300 мс, требует обоснования в PR.
- `prefers-reduced-motion` обязателен: все анимации → 0 мс.
