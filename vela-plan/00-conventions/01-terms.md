# 01 — Термины и идентификаторы

## Глоссарий

| Термин | Значение |
|---|---|
| **Поверхность (surface)** | Одно окно WebView2 со своей ролью: A/Scene, B/UI, C/Overlay |
| **Сцена** | Содержимое фона: фото, видео, 2D-сцена, 3D-сцена, игра |
| **Холст (canvas)** | Бесконечная координатная плоскость, на которой лежат элементы |
| **Элемент** | Объект на холсте: виджет, закреплённый снимок, заметка-стикер, рисунок |
| **Виджет** | Элемент типа `widget`, реализующий контракт `09-widget-spec.md` |
| **Рантайм-хост** | React-приложение в поверхности B, владеющее всеми виджетами монитора |
| **Профиль** | Именованный набор: сцена + раскладка + видимые элементы + правила |
| **Режим ввода** | `edit` / `locked` / `pass-through` — как поверхность B реагирует на мышь |
| **WorkerW** | Служебное окно Explorer, родитель для слоя под иконками |
| **Blur mirror** | Уменьшенная копия сцены внутри B, источник для размытия панелей |
| **Glass** | Панель с размытием содержимого позади неё |
| **Anchor** | Точка привязки элемента к мировым координатам холста |
| **Гейт (gate)** | Набор критериев, без которых этап не закрывается |
| **Pod** | Упакованный установщик + автозапуск + трей (релизная единица) |

## Идентификаторы

| Тип | Формат | Пример | Правило |
|---|---|---|---|
| Этап | `P<n>` | `P3` | не меняется |
| Задача | `T-<этап><двузначный номер>` | `T-0304` | уникален навсегда |
| Подзадача | `ST-<номер задачи>-<номер>` | `ST-0304-02` | уникален навсегда |
| ADR | `ADR-<4 цифры>` | `ADR-0003` | только добавление |
| Риск | `R-<двузначный>` | `R-07` | закрытый не удаляется |
| Открытый вопрос | `OQ-<двузначный>` | `OQ-03` | при закрытии фиксируется ответ |
| Тест-кейс | `TC-<номер задачи>-<номер>` | `TC-0502-03` | живёт в тест-плане задачи |

## Статусы

```
draft ──► ready ──► in-progress ──► review ──► done
  │         │            │
  └─────────┴────────────┴──────► cut (с причиной)
```

- `draft` — ТЗ пишется, брать нельзя.
- `ready` — цель, AC, тест-план и зависимости закрыты.
- `in-progress` — есть исполнитель, один на задачу.
- `review` — PR открыт, второй человек проверяет.
- `done` — AC выполнены, тесты зелёные, план обновлён.
- `cut` — сознательно не делаем; в README обязательна строка `cut-reason:`.

## Приоритеты

- `P0` — блокирует этап; без неё gate не закрывается.
- `P1` — обязательна для релиза, но этап может двигаться дальше.
- `P2` — улучшение; режется первым при нехватке времени.
