# 05 — Тестирование

## Пирамида

| Уровень | Что | Инструмент | Скорость | Обязательность |
|---|---|---|---|---|
| Unit (Rust) | парсер cron, геометрия холста, миграции, валидация схем | `cargo test` | мс | обязателен |
| Unit (TS) | редьюсеры Zustand, хит-тест, снап математика, форматтеры | `vitest` | мс | обязателен |
| Integration (Rust) | окна создаются/уничтожаются, IPC-команды, БД-транзакции | `cargo test --features it` | сек | обязателен |
| Component (UI) | рендер виджета в jsdom, состояния, клавиатура | `vitest` + `@testing-library` | сек | для всех модулей |
| E2E | запуск собранного приложения, сценарии пользователя | `playwright` через `tauri-driver` (WebView2) | мин | для гейтов этапов |
| Visual | регресс стекла/теней/тем | скриншоты + попиксельный дифф с допуском | мин | для P3, P6, P8 |
| Soak | 8 часов работы: утечки памяти, деградация fps | скрипт + снятие метрик | часы | перед релизом |

## Правила написания тестов

- Тест называет поведение, а не метод: `snap_keeps_widget_on_grid_when_within_threshold`.
- Flaky-тест не «перезапускается», а помечается `#[ignore]` / `test.skip` с тикетом.
- Для оконных тестов — обязательный `Drop`-гарант, иначе прогон оставляет окна.
- Скриншот-дифф: допуск 0.2 % пикселей, иначе шум WebGL-сглаживания ломает CI.
- E2E не тестирует то, что покрыто unit: приоритет — сценарии пользователя.

## CI

```
lint ──► typecheck ──► unit (rust+ts) ──► integration ──► build ──► e2e-smoke ──► visual
```
