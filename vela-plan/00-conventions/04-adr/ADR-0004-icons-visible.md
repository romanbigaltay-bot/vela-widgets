# ADR-0004 — Иконки рабочего стола остаются видимыми

**Статус:** принято

## Контекст

Слой A живёт под иконками (WorkerW), слой B — над иконками. Значит, стеклянные панели размывают иконки, попадающие под них.

## Рассмотренные варианты

1. **Прятать иконки автоматически** — чище визуально, но ломает привычку и вызывает вопросы «куда делись файлы».
2. **Оставлять иконки всегда** — привычно, но панель над иконкой выглядит грязно.
3. **Оставлять по умолчанию, предлагать тумблер** — при первом запуске онбординг объясняет выбор, тумблер в настройках, состояние запоминается.

## Решение

Вариант 3. По умолчанию иконки видны; в онбординге один экран с двумя превью и переключателем «Скрыть иконки рабочего стола» (по умолчанию выключен). 

## Последствия

Плюсы: нет сюрпризов, пользователь сам решает.
Минусы: первый экран выглядит менее «чисто», нужен онбординг (и он всё равно нужен для автозапуска).

## Условия пересмотра

Если аналитика покажет, что >70 % пользователей выключают иконки — сделать скрытие поведением по умолчанию.
