# ADR-0008 — Захват через Windows.Graphics.Capture, не GDI

**Статус:** принято

## Контекст

Нужны скриншоты региона, окна, экрана и прокручиваемого содержимого с корректной работой на HDR-дисплеях и при аппаратном ускорении.

## Рассмотренные варианты

1. **GDI BitBlt** — дёшево, но чёрный экран при аппаратном ускорении, неверные цвета при HDR, медленно.
2. **Windows.Graphics.Capture (WGC)** — рисует композитор, корректные цвета, поддержка защиты контента, требует явного согласия на захват окна.
3. **PrintWindow** — падает на многих современных приложениях.

## Решение

Вариант 2 через крейт `windows` (WGC API). Для региона — захват монитора + кроп по координатам. Для прокрутки — серия кадров с эвристикой склейки по перекрытию (фаза P5).

## Последствия

Плюсы: корректные цвета, работает с ускоренными окнами, единый путь для всех режимов.
Минусы: требует создания D3D-устройства в захватывающем потоке, чуть больше кода; на защищённом контенте (DRM) снимок будет чёрным — это обрабатывается явно.

## Условия пересмотра

Пересмотреть при появлении WGC-обёртки в Tauri-плагинах с нужным качеством.
