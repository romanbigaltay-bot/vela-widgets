# 02 — Definition of Done и протокол PR

## DoD подзадачи

Подзадача считается выполненной, когда все пункты истинны одновременно:

1. Код собирается: `cargo clippy --all-targets -- -D warnings` и `tsc --noEmit` чисто.
2. Новые/изменённые ветки покрыты тестами того уровня, что указан в её ТЗ
   (unit / integration / e2e).
3. Ручной сценарий из ТЗ пройден и отмечен в PR.
4. Метрики, затронутые подзадачей, не вышли за бюджет `06-nfr-budget.md`.
5. Нет новых `TODO` без ссылки на идентификатор задачи.
6. Публичные интерфейсы (Rust-типы, IPC-команды, props) задокументированы.
7. План обновлён: статус в README задачи, при необходимости — новая подзадача.
8. Скриншот/запись экрана для UI-работ приложены к PR.

## DoD задачи

- Все подзадачи `done` или `cut` с причиной.
- AC из README задачи выполнены построчно, с указанием, чем проверено.
- Задача закрыта в `manifest.json` (поле `status`, `closed_at`).

## DoD этапа (gate)

- Все `P0`-задачи этапа закрыты.
- Пройден чек-лист выхода этапа (`NN-<этап>/README.md`, раздел «Критерии выхода»).
- Обновлены: `INDEX.md`, `manifest.json`, при необходимости — ADR.
- Проведена сверка оценок (факт/план) и записана в README этапа.

## Протокол PR

- Заголовок: `[ST-0304-02] Снап и направляющие при перетаскивании`.
- Один PR — одна подзадача; исключение — подзадачи < 0.5 дня, допускается
  объединять не более трёх одной задачи.
- Обязательные разделы описания: «Что», «Почему», «Как проверял», «Риски»,
  «Скриншоты» (для UI), «План» (какие файлы плана затронуты).
- Ревью: минимум один человек не автор; для Rust-оконных изменений —
  обязательный второй глаз из-за хрупкости Win32-кода.
- Merge: squash, ветка удаляется. В сообщении коммита — префикс `vela:` и ID.

## Ревью-чеклист

- [ ] Нет состояния, продублированного между Rust/Zustand/SQLite.
- [ ] Нет блокирующих вызовов Win32 в UI-потоке.
- [ ] Все `unsafe` блоки имеют комментарий с инвариантом.
- [ ] Отсутствие магических пауз `sleep` в продакшн-коде.
- [ ] Настройки, влияющие на энергию, уважают профиль питания.
- [ ] Тексты интерфейса — через словарь, без литералов в JSX.
