# T-0503 — Аннотатор

## 1. Цель

Разметка снимка, которая не требует объяснений: знакомые инструменты, аккуратный
вид, недеструктивное редактирование с отменой.

## 2. Инструменты

| Инструмент | Клавиша | Поведение |
|---|---|---|
| Стрелка | `1` | линия с наконечником, толщина 2–6 |
| Рамка | `2` | прямоугольник, скругление 0/4 |
| Текст | `3` | клик → ввод, фон-подложка опционально |
| Хайлайтер | `4` | полупрозрачная полоса, `multiply` |
| Пикселизация | `5` | область с блоками 8–16 px (приватность) |
| Размытие | `6` | gaussian на области |
| Кисть | `7` | свободная линия, сглаживание |
| Шаг-нумерация | `8` | клик → номер по порядку в круге |
| Кроп | `9` | обрезка снимка (деструктивно, с подтверждением) |
| Пипетка | `I` | цвет в буфер как HEX |

- Цвет — 6 свотчей: `--accent`, белый, чёрный, `--danger`, `--ok`, `--warn`.
- Толщина — 3 значения. Отмена/повтор — `Ctrl+Z` / `Ctrl+Shift+Z` (стек 50).

## 3. Модель

- Все аннотации — объекты `{type, points, color, width, ...}` в массиве,
  рисуются на canvas поверх изображения. Недеструктивно до `Ctrl+S`.
- Пикселизация/размытие — применяются на отдельный слой, чтобы не терять
  оригинал; при экспорте «впекаются».
- Экспорт: `Ctrl+C` (буфер), `Ctrl+S` (файл, папка из настроек), `Ctrl+P` (pin).

## 4. Состав подзадач

| ID | Подзадача | Дней |
|---|---|---|
| ST-0503-01 | Канвас, панель инструментов, отмена | 0.6 |
| ST-0503-02 | Фигуры: стрелка, рамка, кисть, текст, шаг-номера | 0.5 |
| ST-0503-03 | Приватность: пикселизация, размытие, кроп, экспорт | 0.4 |

## 5. Критерии приёмки

- **AC-1** Рисование без задержки (≤ 1 кадр), при 4K-снимке тоже.
- **AC-2** `Ctrl+Z` отменяет 50 шагов, `Ctrl+Shift+Z` повторяет.
- **AC-3** Пикселизация делает текст нечитаемым (проверка визуально и тестом
  на «нет высокочастотных деталей» — дисперсия блоков).
- **AC-4** Экспорт PNG сохраняет прозрачность и не теряет разрешение.
- **AC-5** Клавиши 1–9 переключают инструменты, не конфликтуя с вводом текста.

## 6. Тест-план

| ID | Проверка |
|---|---|
| TC-0503-01 | Компонентный: каждый инструмент рисует ожидаемую геометрию |
| TC-0503-02 | Юнит: стек undo/redo (50 шагов, ветвление) |
| TC-0503-03 | Тест приватности: дисперсия блоков после пикселизации |
| TC-0503-04 | E2E: полный поток до файла, сверка размера |

## 7. Риски

Большие снимки (4K) + много аннотаций могут замедлить canvas → рисовать только
изменённый регион (`dirty rect`), экспорт — отдельным проходом.
