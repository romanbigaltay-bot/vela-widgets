# ST-0503-03 — Приватность и экспорт

## Цель

Убрать приватное из снимка так, чтобы оно действительно исчезло, и отдать
результат удобно.

## Реализация

1. Пикселизация: блоки 12 px (настраивается 8–24), усреднение по блоку через
   `drawImage` в миниатюру + `imageSmoothingEnabled = false` обратно.
2. Размытие: `ctx.filter = 'blur(8px)'` на область (или шейдер при недоступности).
3. Кроп: рамка + `Enter` → новый размер изображения с подтверждением (деструктивно,
   но с undo).
4. Экспорт:
   - `Ctrl+C` — `ClipboardItem` с `image/png`;
   - `Ctrl+S` — файл в `%Pictures%\Vela\` (или выбранная папка), имя
     `Vela_YYYY-MM-DD_HH-mm-ss.png`;
   - `Ctrl+P` — pin (T-0504);
   - `Ctrl+Shift+C` — ещё и путь в буфер как текст.
5. Режим «не сохранять на диск»: PNG только в памяти, файл не создаётся.

## Критерии приёмки

- AC-1 Пикселизация: исходный текст не восстановим (дисперсия блоков < порога).
- AC-2 Буфер получает PNG с корректной альфой (вставка в Paint проверена).
- AC-3 Имя файла не коллизирует (добавляется `-2` при совпадении).
- AC-4 «Не сохранять» → файла нет (проверка ФС).

## Тест-план

TC-0503-03, TC-0503-04.

## Риски

R-10 (приватные снимки в кэше) — кэш сессии чистится при выходе; тест проверяет
отсутствие файлов после выхода.
