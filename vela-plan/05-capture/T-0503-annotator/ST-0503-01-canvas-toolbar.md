# ST-0503-01 — Канвас и панель

## Цель

Основа, на которой инструменты подключаются как модули.

## Реализация

1. `Annotator`: `<canvas>` (DPR-aware) + `<img>` снизу (или drawImage фоном).
2. Панель инструментов — вертикальная стеклянная полоса слева: иконки +
   активное состояние, снизу — свотчи цвета и толщина.
3. `useCanvasHistory`: стек снимков `ImageData` только изменённых регионов (dirty rect),
   лимит 50.
4. Координаты: `e.offsetX/Y * dpr` → пиксели изображения.
5. Инструменты регистрируются как `Tool { id, onDown, onMove, onUp, draw(ctx) }`.
6. Клавиши 1–9, `Esc` (выход), `Enter` (применить кроп), `Ctrl+Z/Y`.

## Критерии приёмки

- AC-1 Рисование ≤ 1 кадр задержки.
- AC-2 Undo/redo работает для всех типов инструментов.
- AC-3 Панель не перекрывает выделенную область (автосдвиг, если мешает).

## Тест-план

TC-0503-01, TC-0503-02.

## Риски

`ImageData` на 4K-снимке — 33 МБ на снимок, 50 шагов = 1.6 ГБ → хранить
патчи (region + до/после), не полные снимки.
