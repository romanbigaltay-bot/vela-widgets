# ST-0503-02 — Фигуры

## Цель

Инструменты, которые выглядят «профессионально» с первого штриха.

## Реализация

1. Стрелка: линия + наконечник (треугольник, длина = 4×толщины), сглаживание
   `quadraticCurveTo` при изгибе от перетаскивания.
2. Рамка: `strokeRect` с `lineJoin: round`, опция скругления 0/4.
3. Кисть: сбор точек с `pointermove`, сглаживание (Catmull-Rom → bezier),
   `lineCap: round`.
4. Текст: клик → `contenteditable`-оверлей на канвасе, по `blur` — рендер в canvas;
   авто-подложка `--panel` 70 % для читаемости.
5. Шаг-нумерация: клик → круг 20 px с номером, автоинкремент, сброс при смене
   инструмента.
6. Все фигуры — объекты в массиве, рендерятся каждый кадр (дёшево при < 200).

## Критерии приёмки

- AC-1 Стрелка читается на светлом и тёмном фоне (обводка 1 px контрастная).
- AC-2 Кисть без «угловатости» (визуальная проверка на быстром движении).
- AC-3 Текст не выходит за границы снимка (перенос + ограничение).

## Тест-план

TC-0503-01 + визуальные скриншоты каждого инструмента.

## Риски

Текст через `contenteditable` может давать разное поведение в WebView2 →
фолбэк на `<textarea>` с авторазмером.
