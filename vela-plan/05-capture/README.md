# P5 — Захват экрана, аннотации, pin

**Цель этапа:** снимок экрана за один хоткей, разметка поверх него, «пришпилить»
на бесконечный холст как объект, скопировать в буфер или сохранить.

**Оценка:** 6 дней. **Gate:** G5.

| ID | Задача | Приоритет | Дней | Владелец | Зависит от |
|---|---|---|---|---|---|
| T-0501 | Захват экрана через WGC: регион, окно, экран | P0 | 2.0 | rust | P2 |
| T-0502 | Оверлей выделения региона | P0 | 1.5 | ui+rust | T-0501 |
| T-0503 | Аннотатор: стрелки, рамки, текст, пикселизация | P0 | 1.5 | ui | T-0502 |
| T-0504 | Pin на холст, буфер, сохранение, OCR | P1 | 1.0 | ui+rust | T-0503 |

## Порядок

```
T-0501 ──► T-0502 ──► T-0503 ──► T-0504 ──► G5
```
Цепочка строго последовательная: каждый шаг потребляет результат предыдущего.

## Критерии выхода (G5)

- [ ] `Ctrl+Alt+S` → выделение региона → снимок за ≤ 400 мс после отпускания мыши.
- [ ] Аннотации: стрелка, рамка, текст, хайлайтер, пикселизация — все работают.
- [ ] `Ctrl+C` копирует в буфер, `Ctrl+S` сохраняет, `Ctrl+P` — pin на холст.
- [ ] Pin живёт как элемент холста, перетаскивается, переживает перезапуск.
- [ ] Снимок HDR-дисплея не имеет искажённых цветов (MS-09).
- [ ] Буфер обмена сохраняет прозрачность и корректный формат PNG.
- [ ] Приватное: опция «не сохранять на диск» оставляет только память сессии.

## Что НЕ входит

Запись видео/GIF (вне v1), OCR как отдельный виджет (только действие).

## Риски этапа

- R-07 (HDR) — тест на реальном HDR-экране обязателен до закрытия T-0501.
- R-10 (приватные снимки в кэше) — политика хранения задаётся в T-0504.
