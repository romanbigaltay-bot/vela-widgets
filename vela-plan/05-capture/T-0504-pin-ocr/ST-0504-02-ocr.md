# ST-0504-02 — OCR

## Цель

Текст со снимка в буфер одним действием, без сети и без внешних движков.

## Реализация

1. `ocr::recognize(png_bytes, lang)`:
   - `SoftwareBitmap` из PNG (`BitmapDecoder`);
   - `OcrEngine::TryCreateFromLanguage` (или `TryCreateFromUserProfileLanguages`);
   - `RecognizeAsync` → строки с `BoundingRect`.
2. Склейка строк в абзацы: сортировка по `y`, объединение при пересечении
   по вертикали > 50 % и разрыве по `x` < 12 px.
3. Язык: `settings.capture.ocr_lang`, дефолт — системный; проверка доступности
   на старте.
4. IPC `capture.ocr {assetId}` → `{text, chars}`; UI кладёт в буфер.
5. Ограничение: изображение > 8K предварительно уменьшается до 4K (быстрее, точность
   не падает).

## Критерии приёмки

- AC-1 Точность ≥ 90 % на 5 фикстурах (ru/en).
- AC-2 ≤ 600 мс на 1440p.
- AC-3 Отсутствие языкового пакета → `PlatformUnavailable` с понятным текстом.

## Тест-план

TC-0504-02 с фикстурами, сравнение по нормализованному тексту (без регистра
и пробелов).

## Риски

WinRT API требует правильной инициализации COM-потока → отдельный поток с MTA.
