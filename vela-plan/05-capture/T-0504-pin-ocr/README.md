# T-0504 — Pin и OCR

## 1. Цель

Снимок становится объектом рабочего стола: его можно отодвинуть, он остаётся
на месте, к нему возвращаются. Плюс текст с картинки — в буфер.

## 2. Pin как элемент

- Новый `kind: 'pin'` с `settings: {path, naturalWidth, naturalHeight, fit:'contain'|'cover'}`.
- На холсте ведёт себя как виджет: перетаскивание, ресайз (с сохранением
  пропорций при `Shift`), z-order.
- Масштаб картинки: рендер через `<img>` с `image-rendering: auto`, качество
  не теряется при малом размере.
- Двойной клик — открыть в аннотаторе; `Delete` — удалить (файл остаётся в
  истории, если не «приватный» режим).

## 3. OCR

- Движок: `Windows.Media.Ocr` (системный, без зависимостей и без сети).
- Языки: из системы (ru/en/…), выбор в настройках.
- Действие: `capture.ocr {id}` → текст → буфер + тост «Скопировано N символов».
- Строки собираются в абзацы по геометрии (сортировка по `y`, склейка с `x`-разрывом).
- Если текст не найден → тост «Текст не распознан», не пустой буфер.

## 5. Критерии приёмки

- **AC-1** Pin переживает перезапуск, показывает то же изображение.
- **AC-2** Pin при 200×120 не мылится и не растягивается непропорционально.
- **AC-3** OCR: точность ≥ 90 % на скриншоте текста 12 pt (ru/en).
- **AC-4** OCR ≤ 600 мс на 1440p-снимке.
- **AC-5** История: последние 50 снимков, старые чистятся, «приватные» не хранятся.

## 7. Риски

OCR зависит от установленных языковых пакетов Windows → проверка на старте,
сообщение «Русский язык OCR не установлен».
Файлы pin могут «потеряться» при очистке кэша → pin-файлы в отдельной папке,
не в кэше.
