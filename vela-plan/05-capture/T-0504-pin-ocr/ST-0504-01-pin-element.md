# ST-0504-01 — Pin

## Цель

Снимок живёт на холсте как равноправный объект, а не как «окно поверх».

## Реализация

1. `PinElement`: `WidgetCard` без заголовка (или с минимальным), содержимое —
   `<img src="asset://...">`.
2. `settings`: `{assetId, naturalW, naturalH, fit}`; путь не хранится напрямую
   (только `assetId`), чтобы не ломаться при переносе данных.
3. Ресайз: сохраняет пропорции по умолчанию, `Shift` — свободно.
4. `asset://` — протокол Tauri, доступ только к папке `pins/`.
5. Двойной клик — `overlay.open {mode:'annotator', assetId}`.

## Критерии приёмки

- AC-1 Перезапуск сохраняет изображение (assetId валиден).
- AC-2 Пропорции сохраняются, изображение не мылится.
- AC-3 Ссылка на отсутствующий файл даёт плашку «Изображение недоступно», не битую иконку.

## Тест-план

TC-0504-01 + тест с удалённым файлом.

## Риски

`asset://` требует настройки scope в Tauri — узкий список папок, не весь диск.
