# T-0502 — Оверлей выделения

## 1. Цель

Знакомое и мгновенное выделение области: затемнение, рамка, размер в пикселях,
магнификация, привязка к окнам.

## 2. Поведение

- Открывается на мониторе с курсором (или на всех, если выделение переходит границу).
- Фон — затемнение 40 % от снимка экрана (не живой экран: снимок уже сделан, это
  исключает «мигание» и позволяет выделять по неподвижной картинке).
- Рамка: 1 px `--accent`, углы-маркеры 8 px, размер `W×H` в чипе рядом с курсором.
- Магнификация: кружок 120 px с 4× увеличением в углу (опция).
- Привязка: `Alt` — свободно; иначе — к краям окон (`EnumWindows` + `DwmGetWindowAttribute`
  для реальных границ без тени) и к краям монитора, порог 8 px.
- `Esc` — отмена; `Enter` — подтвердить текущее; двойной клик — окно под курсором.

## 3. Реализация

- Оверлей C, режим `region`. Рисование — canvas поверх изображения снимка.
- Список окон приходит из Rust (`capture.windows_list`) один раз при открытии.
- Подтверждение → `capture.request {mode:'region', rect}` → PNG → переход в
  аннотатор (T-0503) в том же оверлее.

## 4. Состав подзадач

| ID | Подзадача | Дней |

| ST-0502-01 | Открытие оверлея со снимком, затемнение, координаты | 0.6 |

| ST-0502-03 | Подтверждение, отмена, переход в аннотатор | 0.4 |

## 5. Критерии приёмки

- **AC-1** Оверлей появляется ≤ 150 мс после хоткея.
- **AC-2** Выделение мышью даёт точные координаты (±1 физический пиксель).
- **AC-3** Привязка к окну срабатывает при 8 px, не срабатывает при 12 px.
- **AC-4** `Esc` закрывает оверлей, фокус возвращается.
- **AC-5** На двух мониторах выделение через границу работает.

## 7. Риски

Затемнение по снимку «замораживает» экран — если что-то изменилось (видео),
это заметно; предупреждение в настройках не нужно, но в документации отметить.
