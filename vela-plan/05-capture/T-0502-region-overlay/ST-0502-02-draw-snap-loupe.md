# ST-0502-02 — Выделение и привязка

## Цель

Выделение «попадает» туда, куда целился, без микродвижений.

## Реализация

1. `pointerdown` → начало, `pointermove` → прямоугольник (нормализация по
   min/max, любое направление), `pointerup` → подтверждение.
2. Размеры: чип `W × H` у курсора, `tabular-nums`.
3. Привязка к окнам: список из `capture.windows_list` (rect + z + title);
   сравнение 4 краёв с порогом 8 CSS-px; приоритет — самое верхнее окно.
4. Магнификация: canvas 120×120, `drawImage` с `imageSmoothingEnabled = false`,
   увеличение 4×, позиционирование так, чтобы не закрывать курсор.
5. `Alt` — отключить и привязку, и магнификацию.

## Критерии приёмки

- AC-1 Прямоугольник корректен при выделении в любом из 4 направлений.
- AC-2 Привязка срабатывает при 8 px, не при 12 px.
- AC-3 Магнификация показывает пиксели без сглаживания.

## Тест-план

TC-0502-01, TC-0502-02.

## Риски

Список окон может быть большим (100+) → фильтр по видимости и размеру > 40×40.
