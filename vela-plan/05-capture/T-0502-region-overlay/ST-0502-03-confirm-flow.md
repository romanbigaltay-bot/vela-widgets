# ST-0502-03 — Подтверждение

## Цель

Один поток без «а теперь куда»: выделил → разметил → сохранил.

## Реализация

1. `pointerup` с площадью > 100 px² → `capture.request {mode:'region', rect}`,
   показ спиннера в чипе размера (не блокирующий экран).
2. Ответ `capture.ready` → тот же оверлей переключается в режим `annotator`
   с изображением (T-0503), история навигации — стек, `Esc` возвращает к выделению.
3. Площадь < 100 px² → игнор (случайный клик), остаётся в режиме выделения.
4. `Enter` — подтвердить текущее выделение; `Ctrl+A` — весь монитор.
5. Все ошибки (`Busy`, `PlatformUnavailable`) → тост с причиной, оверлей не
   закрывается.

## Критерии приёмки

- AC-1 `capture.ready` обрабатывается ≤ 400 мс, спиннер виден.
- AC-2 `Esc` из аннотатора возвращает к выделению, не закрывает всё.
- AC-3 Ошибка захвата не теряет снимок экрана (можно повторить).

## Тест-план

TC-0502-03, ручной сценарий полного потока.

## Риски

Двойное нажатие `Enter` может отправить два запроса → блокировка кнопки до ответа.
