# ST-0502-01 — Оверлей со снимком

## Цель

Снимок показывается до того, как пользователь начнёт выделять; координаты
однозначны.

## Реализация

1. Хоткей → Rust: захват всех мониторов (одним устройством, по очереди) →
   PNG в кэш сессии → `overlay.open { mode: 'region', shots: [{monitor, path, rect}] }`.
2. C создаётся на объединённом bbox всех мониторов (одно окно на всё).
3. UI: `<img>` на монитор, `object-fit: none`, абсолютные координаты;
   затемнение — `div` с `background: rgba(0,0,0,.4)` и «дыркой» через `clip-path`.
4. Координаты: все вычисления — в CSS-пикселях объединённого bbox; при отправке
   в Rust — умножение на `scale` соответствующего монитора.
5. `Escape`/клик вне — `overlay.close`.

## Критерии приёмки

- AC-1 Снимок на экране ≤ 150 мс после хоткея.
- AC-2 Координаты выделения в PNG совпадают ±1 px (тест с известным паттерном).
- AC-3 Мультимонитор с разным DPI — координаты верны на обоих.

## Тест-план

TC-0502-01, TC-0502-03.

## Риски

Смешение DPI — самая частая причина «сдвига на 20 %»; тест с паттерном на каждом
мониторе обязателен.
