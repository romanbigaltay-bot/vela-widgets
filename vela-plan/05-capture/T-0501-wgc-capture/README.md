# T-0501 — Захват через WGC

## 1. Цель

Получать кадр экрана/окна в PNG без чёрных областей, с корректными цветами,
за ≤ 120 мс на 1440p.

## 2. Решение

`Windows.Graphics.Capture` (ADR-0008):
1. Создаём `ID3D11Device` + `Direct3D11CaptureFramePool`, `GraphicsCaptureSession`.
2. Для монитора — `CreateForMonitor`; для окна — `CreateForWindow` (нужно согласие
   на захват, Windows показывает жёлтую рамку — это нормально и должно быть
   объяснено в UI).
3. Первый кадр через `frame_arrived` → `CopyResource` в staging texture →
   `Map` → RGBA → PNG (`image` crate, аппаратно не ускоряется, но 1440p ~40 мс).
4. `session.close()` сразу после кадра — не держим захват постоянно.
5. Для региона — захват монитора + кроп по прямоугольнику (быстрее и надёжнее,
   чем отдельный пайплайн).

## 3. Производительность

| Шаг | Бюджет |
|---|---|
| Создание устройства (кэшируется между вызовами) | ≤ 20 мс первый раз, ≤ 2 мс далее |
| Ожидание кадра | ≤ 40 мс |
| Copy + Map | ≤ 25 мс (1440p) |
| PNG encode | ≤ 45 мс (1440p) → опционально async в пуле |
| Итого | ≤ 120 мс |

## 4. Тонкости

- Защищённый контент (DRM) → чёрный кадр; детектируем (все пиксели < 8) и
  сообщаем «Контент защищён».
- HDR: WGC отдаёт `DXGI_FORMAT_R16G16B16A16_FLOAT`; нужен tonemap в sRGB
  (простая кривая Reinhard + gamma), иначе цвета «выжжены».
- Курсор не включается по умолчанию (опция).
- Масштаб: захват в физических пикселях монитора; координаты региона приходят
  в CSS-пикселях и умножаются на `scale`.

## 6. Критерии приёмки

- **AC-1** Снимок монитора 1440p ≤ 120 мс (замер 20 прогонов).
- **AC-2** Цвета совпадают с экраном: средняя дельта ≤ 2 % по 9 зонам (SDR).
- **AC-3** HDR-дисплей: нет «выжженных» участков, дельта ≤ 5 %.
- **AC-4** Защищённый контент → понятное сообщение, не чёрный PNG.
- **AC-5** Захват не оставляет сессию открытой (рамка захвата исчезает).

## 8. Риски

- R-07 (HDR) — tonemap обязателен, тест на реальном HDR.
- Требуется D3D-устройство в отдельном потоке; нельзя в UI-потоке (фриз).
- Антивирусы могут реагировать на захват экрана — только по хоткею, без фонового
  захвата, подпись бинаря.
