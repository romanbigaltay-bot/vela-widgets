# ST-0501-03 — IPC захвата

## Цель

Единая точка входа для всех видов захвата, с понятным состоянием.

## Реализация

1. `capture.request { mode: 'region'|'window'|'screen'|'scroll', monitor?, rect? }`
   → `capture.ready { id, path?, bitmapHandle?, rect, monitor }`.
2. Хоткей `Ctrl+Alt+S` → открывает оверлей C в режиме `annotator` с выбором
   региона (T-0502).
3. События: `capture.started`, `capture.ready`, `capture.failed {code}`.
4. Запись метаданных в `capture_history` (без файла при «не сохранять»).
5. Защита от параллельных захватов: `Busy` при активном.

## Критерии приёмки

- AC-1 Два вызова подряд: второй получает `Busy`, не падает.
- AC-2 `capture.ready` приходит ≤ 400 мс после отпускания мыши.
- AC-3 Метаданные пишутся в историю (кроме режима «не сохранять»).

## Тест-план

Интеграционный тест: вызов → событие → файл существует и валиден.

## Риски

Передача больших битмапов через IPC — медленно; передаём путь/хендл, а данные —
через файл или shared memory (для pin — файл в кэше сессии).
