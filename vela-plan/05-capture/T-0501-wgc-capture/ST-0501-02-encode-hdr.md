# ST-0501-02 — Кодирование и HDR

## Цель

PNG без искажений цвета на SDR и HDR дисплеях, достаточно быстро.

## Реализация

1. Детект формата кадра: `B8G8R8A8_UNorm` (SDR) или `R16G16B16A16_Float` (HDR).
2. SDR: BGRA → RGBA, без преобразований.
3. HDR: `linear * exposure` → Reinhard tonemap → sRGB gamma → 8 бит.
   Экспозиция подбирается по средней яркости (авто), с опцией ручной.
4. Кодирование: `png` crate, `Compression::Fast` (размер не критичен), в пуле
   потоков, чтобы не блокировать UI.
5. Кэш последних 5 снимков в памяти (для pin/аннотаций без перечитывания диска).
6. Опция «не сохранять на диск»: PNG только в памяти, путь не создаётся.

## Критерии приёмки

- AC-1 PNG 1440p ≤ 45 мс.
- AC-2 Дельта цвета SDR ≤ 2 % по 9 зонам.
- AC-3 HDR: нет клиппинга в светах (проверка гистограммы).
- AC-4 При «не сохранять» файл на диске не появляется (проверка файловой системы).

## Тест-план

TC-0501-01, TC-0501-03 + автотест гистограммы для HDR-фикстуры.

## Риски

Автоэкспозиция может «пересветить» тёмный интерфейс → консервативный
коэффициент (0.9 от расчётного) и ручная настройка.
