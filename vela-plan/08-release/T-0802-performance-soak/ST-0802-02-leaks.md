# ST-0802-02 — Утечки

## Цель

Закрыть найденные утечки, а не «списать на WebView2».

## Реализация

1. Каждая утечка — отдельный тикет с профилем до/после.
2. Типовые кандидаты: битмапы без `close()`, текстуры без `deleteTexture`,
   подписки на события без отписки, `setInterval` в модулях, растущий лог-буфер.
3. Проверка после исправления: повторный прогон того же сценария.
4. Если утечка внутри WebView2 (подтверждено) — документировать с обходом
   (периодическое пересоздание поверхности при простое > 6 ч — опция).

## Критерии приёмки

- AC-1 Ни одной подтверждённой утечки в нашем коде.
- AC-2 Повторный прогон показывает стабильную память.
- AC-3 Для внешних утечек есть обход и запись в известных ограничениях.

## Тест-план

Повторные прогоны из ST-0802-01.

## Риски

Пересоздание поверхности может мигать → только при длительном простое и
с предварительной подготовкой нового окна.
