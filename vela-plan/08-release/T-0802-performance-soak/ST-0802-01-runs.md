# ST-0802-01 — Прогоны

## Цель

Цифры, по которым можно принимать решение о релизе.

## Реализация

1. Скрипт `bench/run_all.ps1`: последовательно прогоняет 6 сценариев,
   сохраняет CSV + графики.
2. Таблица факт/план по каждой метрике из бюджета.
3. Для отклонений — гипотеза причины и ссылка на задачу исправления.
4. Артефакты в `bench/out/<date>/`, приложены к PR.

## Критерии приёмки

- AC-1 Все 6 прогонов выполнены.
- AC-2 Таблица заполнена, отклонения объяснены.
- AC-3 Артефакты доступны.

## Тест-план

Сам скрипт.

## Риски

Разные машины дают разные цифры → фиксированная эталонная конфигурация и
второй прогон на «слабой» машине для проверки деградации.
