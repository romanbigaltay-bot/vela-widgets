# ST-0801-03 — RDP и виртуальные машины

## Цель

Приложение работает везде, даже где нет GPU и рабочего стола.

## Реализация

1. Прогон M8–M10.
2. RDP: детект `GetSystemMetrics(SM_REMOTESESSION)`, сцена отключена, тост.
3. VM без аппаратного ускорения: детект через `chrome://gpu`-подобную проверку
   (`WEBGL_debug_renderer_info` содержит `SwiftShader`/`llvmpipe`) → качество 1,
   матовое стекло.
4. Логирование выбранного профиля деградации при старте.

## Критерии приёмки

- AC-1 RDP: приложение запускается, виджеты работают, сцена отключена.
- AC-2 VM: fps ≥ 30, стекло матовое, нет «чёрных» панелей.
- AC-3 Профиль деградации виден в диагностике.

## Тест-план

Ручной прогон на VM и через RDP.

## Риски

Детект software-рендера не 100 % надёжен → если fps < 20 три раза подряд,
принудительно включить деградацию.
