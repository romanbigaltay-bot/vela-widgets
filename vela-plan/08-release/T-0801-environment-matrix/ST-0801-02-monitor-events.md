# ST-0801-02 — События мониторов

## Цель

Отключение/подключение экрана и смена разрешения не ломают раскладку.

## Реализация

1. Прогон M5–M7, фиксация поведения и скриншотов.
2. Проверка `orphaned`-зоны: элементы доступны, не потеряны.
3. При подключении нового монитора — пустой вьюпорт, без дублей элементов.
4. Смена разрешения: пересчёт геометрии без «прыжка» камеры.
5. Исправления по результатам.

## Критерии приёмки

- AC-1 После отключения все элементы видны на основном мониторе.
- AC-2 После подключения нет дублей.
- AC-3 Камера не «прыгает» при смене разрешения.

## Тест-план

Ручной прогон + автоматические проверки геометрии.

## Риски

События приходят пачкой при docking station → дебаунс 500 мс на пересчёт.
