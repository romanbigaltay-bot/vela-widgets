# ST-0801-01 — DPI и стекло

## Цель

Одинаково чёткая картинка на любом масштабе и любом числе мониторов.

## Реализация

1. Прогон M1–M4, фиксация скриншотов и метрик (fps, память).
2. Проверка: `devicePixelRatio` в каждом вьюпорте соответствует монитору.
3. Стекло: blur-таргет в физических пикселях монитора, не в CSS.
4. Текст: проверка отсутствия «мыла» (сравнение резкости краёв на скриншотах).
5. Исправления по результатам, каждое — отдельный коммит с описанием.

## Критерии приёмки

- AC-1 Чёткость текста на 150/200 % не хуже, чем на 100 %.
- AC-2 Стекло совпадает по положению с панелью ±1 px на всех DPI.
- AC-3 Метрики в норме на M3/M4 (память +90 МБ максимум на второй монитор).

## Тест-план

Скриншоты + автоматическая проверка геометрии.

## Риски

Смешение DPI — самый частый источник багов; правило «физические пиксели в Rust,
CSS в UI» проверяется в ревью каждого коммита этапа.
