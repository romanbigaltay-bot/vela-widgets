# P8 — Упрочнение и релиз

**Цель этапа:** превратить работающее приложение в продукт, который переживает
чужие машины: разные DPI, несколько мониторов, RDP, слабое железо, антивирус,
обновления и удаление без следов.

**Оценка:** 6 дней. **Gate:** G8 (релиз-кандидат).

| ID | Задача | Приоритет | Дней | Владелец | Зависит от |
|---|---|---|---|---|---|
| T-0801 | Мультимонитор, DPI, RDP: матрица окружений | P0 | 1.5 | rust | P2, P3 |
| T-0802 | Производительность и soak | P0 | 1.0 | оба | все |
| T-0803 | Установщик, обновления, удаление | P0 | 1.5 | rust | — |
| T-0804 | Настройки, онбординг, доступность | P1 | 1.0 | ui | все |
| T-0805 | Наблюдаемость: логи, отчёты, диагностика | P1 | 1.0 | rust | — |

## Порядок

```
T-0801 ──┐
T-0802 ──┼──► T-0804 ──► G8
T-0803 ──┤
T-0805 ──┘
```
T-0801 и T-0802 идут параллельно (разные люди), T-0804 требует стабильных
настроек, T-0805 — независим.

## Критерии выхода (G8)

- [ ] Матрица окружений из `05-testing.md` пройдена целиком, баги заведены/исправлены.
- [ ] Soak 8 часов: память не растёт > 5 %, fps стабилен.
- [ ] Установщик: установка/обновление/удаление без следов (кроме данных пользователя).
- [ ] Автообновление работает с откатом при сбое.
- [ ] Онбординг: 4 экрана, понятно с первого раза (тест на 5 людях).
- [ ] Доступность: полная навигация с клавиатуры, `reduced-motion`, контраст.
- [ ] Логи и диагностика: «Собрать отчёт» даёт zip без приватных данных.
- [ ] Нет открытых `P0`-багов.

## Релизный чек-лист (краткий)

1. Версия в `tauri.conf.json` и `Cargo.toml` совпадает.
2. Подпись бинаря и установщика (EV-сертификат или self-signed для беты).
3. Changelog на русском и английском.
4. Бэкап схемы БД: миграции проверены на данных предыдущей версии.
5. Проверка на «чистой» виртуалке Windows 11 без WebView2 (должен предложить установку).
6. Откат: предыдущая версия доступна в канале.
