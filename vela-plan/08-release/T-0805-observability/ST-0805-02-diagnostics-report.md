# ST-0805-02 — Отчёт

## Цель

Один файл, который можно попросить у пользователя, и он не страшный.

## Реализация

1. `diagnostics::collect() -> zip` в `%TEMP%\Vela-diagnostics-<ts>.zip`.
2. Содержимое: `version.txt`, `logs/*.log` (последние 3), `surfaces.json`,
   `metrics.json`, `config-redacted.json`, `monitors.json`.
3. `config-redacted`: ключи приватных настроек заменяются на `«скрыто»`.
4. UI: список файлов и размеров перед «Сохранить как…», никакой отправки.
5. Кнопка «Открыть папку» после сохранения.

## Критерии приёмки

- AC-1 Отчёт собирается ≤ 3 с.
- AC-2 Приватные значения отсутствуют.
- AC-3 Пользователь видит состав до сохранения.

## Тест-план

TC-0805-02.

## Риски

Логи могут быть большими → только последние 3 файла и лимит 5 МБ на архив.
