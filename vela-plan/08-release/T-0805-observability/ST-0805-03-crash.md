# ST-0805-03 — Падения

## Цель

Падение не должно быть «тихим»: пользователь знает, что случилось, и может
помочь.

## Реализация

1. Panic-hook в Rust: запись в лог + файл `crash-<ts>.json` (сообщение, backtrace
   без путей пользователя, версия).
2. UI: глобальный `error`-обработчик → тот же механизм.
3. При старте: если есть свежие падения (< 24 ч) — баннер «Приложение закрылось
   с ошибкой. Отправить отчёт?» (превью содержимого).
4. Лимит 5 файлов, старые удаляются.
5. После 3 падений за 10 минут — безопасный режим (без сцены, без WorkerW).

## Критерии приёмки

- AC-1 Падение фиксируется с backtrace.
- AC-2 Баннер появляется при следующем старте.
- AC-3 Безопасный режим включается после 3 падений.

## Тест-план

TC-0803-03 (искусственный краш) + проверка баннера.

## Риски

Безопасный режим может «застрять» → выход из него по явному действию
пользователя или после успешного старта.
