# ST-0805-01 — Логи

## Цель

Достаточно информации для разбора, ноль приватного.

## Реализация

1. `tracing-subscriber` с `rolling_file_appender` (ежедневно, 7 файлов).
2. Формат: `ts level target msg key=value`, без ANSI в файле.
3. `--debug` повышает уровень; в настройках — «Подробные логи (до перезапуска)».
4. Редакция: `RedactedUrl` (только хост), запрет `Debug`-печати структур с
   пользовательскими данными (кастомные impl).
5. UI-логи: `invoke`-обёртка пишет ошибки и медленные вызовы (> 500 мс).

## Критерии приёмки

- AC-1 Ротация работает, 8-й день удаляет старейший.
- AC-2 В логах нет содержимого заметок/буфера (тест с «секрет»).
- AC-3 Медленные IPC-вызовы логируются.

## Тест-план

TC-0805-01, TC-0805-02.

## Риски

`Debug` для структур с текстом легко случайно вывести → линт/ревью, кастомные
`impl Debug` с редакцией.
