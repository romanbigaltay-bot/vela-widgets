# ST-0803-03 — Удаление

## Цель

Уйти, не оставив мусора, но не уничтожив данные без спроса.

## Реализация

1. NSIS uninstaller: остановить процесс, удалить `Run`-ключ, ярлыки, папку
   программы, кэш (`%LOCALAPPDATA%\Vela\cache`, `captures` по выбору).
2. Диалог: «Сохранить настройки и раскладку?» (по умолчанию — да).
3. При сохранении остаются: `state.db`, `pins/`, `logs/` (опционально).
4. Проверка после удаления: нет процессов, нет ключей, нет папки программы.

## Критерии приёмки

- AC-1 После удаления не остаётся файлов в `Programs` и `Run`.
- AC-2 При «сохранить» данные на месте и читаются после переустановки.
- AC-3 Нет висящих процессов.

## Тест-план

TC-0803-04.

## Риски

Удаление папки с данными по ошибке — недопустимо: только по явному выбору
«удалить данные».
