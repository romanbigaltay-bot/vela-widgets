# T-0803 — Установщик

## 1. Цель

Установка без вопросов, обновление без потери данных, удаление без следов
(кроме данных пользователя, которые он может сохранить).

## 2. Решение по OQ-01

**NSIS как основной установщик** (Tauri default), MSIX — опция позже.
Обоснование: NSIS даёт контроль над папкой установки и автозапуском, не требует
подписи для беты (но подписываем), проще откат. MSIX-ограничения (виртуализация
реестра) ломают наш `Run`-ключ и WorkerW-поведение.

## 3. Установка

- Папка: `%LOCALAPPDATA%\Programs\Vela` (без прав администратора).
- Опции на экране установки: «Запускать при входе в Windows» (по умолчанию
  включено, объяснено), «Запустить сейчас».
- Проверка WebView2: если отсутствует — предложить установку (Evergreen Bootstrapper
  в комплекте или ссылка).
- Проверка ОС: Windows 11 22H2+, иначе понятное сообщение (не «тихий отказ»).

## 4. Обновления

- Канал: stable/beta, проверка раз в 6 ч (только если включено).
- Подпись: обновление проверяется по подписи, иначе не применяется.
- Установка: скачивание в фоне → «Перезапустить и обновить» → сохранение
  состояния (flush БД) → перезапуск.
- Откат: при неудачном старте новой версии (3 краша за 10 минут) — автоматический
  возврат к предыдущей с тостом.

## 5. Удаление

- Убирает автозапуск, ярлыки, бинарь, кэш.
- Спрашивает: «Сохранить настройки и раскладку?» → если да, оставляет `state.db`
  и `pins/`, если нет — удаляет.
- Не оставляет процессов и служб.

## 7. Критерии приёмки

- **AC-1** Установка на чистую VM ≤ 60 с, без прав администратора.
- **AC-2** Обновление с версии N-1 сохраняет раскладку и настройки.
- **AC-3** Откат при трёх крашах работает (проверено искусственным крашем).
- **AC-4** Удаление не оставляет файлов в `Programs`, `Run`, `Temp` (кроме
  сохранённых данных).
- **AC-5** Отсутствие WebView2 → понятное предложение установки.

Антивирус может блокировать установщик без подписи → подпись обязательна для
публичного релиза; для беты — предупреждение в документации.
