# ST-0803-01 — Установщик

## Цель

Установка, которая не задаёт лишних вопросов и не требует прав.

## Реализация

1. `tauri.conf.json → bundle`: `targets: ["nsis"]`, `nsis.installMode: "currentUser"`,
   `languages: ["Russian","English"]`, `installerIcon`.
2. Кастомные хуки NSIS: проверка версии Windows (`AtLeastWin11Build 22621`),
   проверка WebView2 (`HKLM\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\...`),
   опция автозапуска (запись ключа после установки, если выбрана).
3. Ярлык в меню «Пуск» (не на рабочем столе по умолчанию — рабочий стол занят
   виджетами).
4. `--autostart` аргумент уже поддержан (T-0204).
5. Логи установки в `%TEMP%\Vela-install.log`.

## Критерии приёмки

- AC-1 Установка ≤ 60 с на чистой VM.
- AC-2 Без WebView2 — понятное сообщение с кнопкой установки.
- AC-3 Автозапуск включается только если выбрано.

## Тест-план

TC-0803-01.

## Риски

NSIS + кириллица в путях → проверить установку в путь с русскими буквами.
