# T-0804 — Настройки и онбординг

## 1. Цель

Пользователь понимает, что произошло с его рабочим столом, и может всё
настроить. Плюс доступность — не «галочка», а реальная работа без мыши.

## 2. Настройки

Разделы: «Общее» (язык, тема, автозапуск), «Сцена» (источник, качество,
энергия), «Холст» (сетка, снап, камеры), «Виджеты» (список, права, настройки),
«Захват» (папка, формат, OCR), «Горячие клавиши», «Приватность» (история, буфер,
логи), «О программе» (версия, диагностика, обновления).

- Поиск по настройкам (`Ctrl+F` внутри окна).
- Изменения применяются сразу (без «Сохранить»), с возможностью сброса раздела.
- Каждая настройка с пояснением в одну строку (tooltip/подпись).

## 3. Онбординг (первый запуск)

1. Приветствие: «Vela превращает рабочий стол в рабочее пространство» + превью.
2. Иконки рабочего стола: оставить/скрыть (ADR-0004) с превью обоих вариантов.
3. Сцена: 3 варианта (фото/aurora/видео) — выбрать сразу.
4. Виджеты: 4 рекомендованных (часы, заметки, календарь, таймер) — включить/нет.
5. Автозапуск: «Запускать при входе в Windows» (включено).
Итого 5 экранов, каждый можно пропустить, всё меняется потом.

## 4. Доступность

- Полная навигация с клавиатуры: `Tab`-порядок логичен, фокус-кольцо видно на
  любом фоне (2 px `--accent` + 1 px offset + тень).
- `prefers-reduced-motion` → все анимации 0 мс, crossfade заменяется мгновенной
  сменой.
- Контраст: все текстовые токены ≥ 4.5:1 (кроме декоративных).
- Скринридеры: `aria-label` на иконочных кнопках, `role` для чекбоксов/переключателей,
  живой регион для тостов.
- Масштаб интерфейса: настройка 90–150 % (умножение токенов типографики),
  независимо от системного DPI.

## 6. Критерии приёмки

- **AC-1** Все настройки применяются без перезапуска (кроме тех, что требуют).
- **AC-2** Поиск находит настройку по названию и синониму.
- **AC-3** Онбординг проходится за ≤ 90 с, можно пропустить.
- **AC-4** Полный проход по интерфейсу с клавиатуры без «ловушек» фокуса.
- **AC-5** `reduced-motion` отключает все анимации (проверка по счётчику кадров).
- **AC-6** Масштаб 150 % не ломает вёрстку виджетов (проверка скриншотами).

## 8. Риски

Настройки легко превращаются в «свалку» → правило: новая настройка появляется
только если у неё есть понятное объяснение и дефолт, не требующий изменения.
