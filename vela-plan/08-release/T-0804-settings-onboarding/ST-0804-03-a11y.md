# ST-0804-03 — Доступность

## Цель

Интерфейс работает для людей, которые не пользуются мышью или плохо видят.

## Реализация

1. Фокус-менеджмент: `:focus-visible` на всех интерактивных, порядок `Tab`
   соответствует визуальному, `Escape` закрывает верхний слой.
2. `aria`: роли для `Switch`/`Checkbox`/`Menu`, `aria-live="polite"` для тостов,
   `aria-label` на иконочных кнопках.
3. `reduced-motion`: глобальный CSS + JS-флаг для rAF-цикла.
4. Масштаб интерфейса: `--ui-scale` 0.9–1.5, применяется к типографике и отступам,
   проверяется на отсутствие переполнений.
5. Тест на ловушки фокуса: автотест «Tab 100 раз не зацикливается в модалке».

## Критерии приёмки

- AC-1 Полный обход интерфейса с клавиатуры.
- AC-2 Narrator читает назначение иконочных кнопок.
- AC-3 `reduced-motion` = 0 кадров анимации.
- AC-4 Масштаб 150 % без переполнений.

## Тест-план

TC-0804-02, TC-0804-03, TC-0804-04.

## Риски

Кастомные чекбоксы/переключатели легко сделать недоступными → использовать
нативные элементы с визуальной стилизацией, а не `div` с ролью.
