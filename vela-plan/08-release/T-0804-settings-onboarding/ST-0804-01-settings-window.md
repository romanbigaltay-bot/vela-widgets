# ST-0804-01 — Настройки

## Цель

Найти и изменить любую настройку за ≤ 15 с.

## Реализация

1. Оверлей C в режиме `settings`: левая навигация (8 разделов), правая — контент.
2. Каждая настройка — компонент `Setting { key, label, hint, control }` из реестра;
   реестр генерирует и поиск, и валидацию.
3. Применение сразу: `app.settings_set` (дебаунс 300 мс для слайдеров).
4. Поиск: фильтр по `label + hint + keywords`, подсветка совпадений.
5. «Сбросить раздел» — значения по умолчанию из реестра.

## Критерии приёмки

- AC-1 Все 8 разделов открываются ≤ 100 мс.
- AC-2 Поиск «размытие» находит настройки стекла.
- AC-3 Сброс раздела работает и отражается в UI.

## Тест-план

E2E + юнит реестра настроек.

## Риски

Дубли ключей настроек → проверка уникальности на старте в dev.
