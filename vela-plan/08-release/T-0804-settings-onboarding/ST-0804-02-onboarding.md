# ST-0804-02 — Онбординг

## Цель

За 90 секунд объяснить, что произошло с рабочим столом и как всё вернуть.

## Реализация

1. 5 экранов из README, каждый с превью (реальный рендер, не картинка).
2. Прогресс-точки, «Пропустить» на всех экранах, `Esc` — пропустить всё.
3. Выбор сохраняется в `settings.onboarding_done` + значения.
4. Возврат к онбордингу из настроек («Показать знакомство снова»).
5. Никаких модальных блокировок: если пользователь закрыл — работает с дефолтами.

## Критерии приёмки

- AC-1 Прохождение ≤ 90 с (замер на 5 людях).
- AC-2 Пропуск оставляет разумные дефолты.
- AC-3 Повторный показ из настроек работает.

## Тест-план

TC-0804-01 + юзабилити-прогон.

## Риски

Первый запуск может совпасть с медленной загрузкой сцены → показывать онбординг
после готовности холста, не раньше.
