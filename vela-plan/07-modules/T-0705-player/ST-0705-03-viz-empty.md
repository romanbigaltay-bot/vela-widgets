# ST-0705-03 — Визуализатор и пустое состояние

## Цель

Живой элемент, когда музыка есть, и деликатная тишина, когда нет.

## Реализация

1. 22 полосы, высота из `scene.audio_frame` (8 полос → интерполяция до 22),
   обновление 30 fps, `transition: height 60ms linear`.
2. Остановка при `!playing` (полосы → 6 %) и при `occluded`.
3. Пустое состояние: иконка + «Ничего не играет», `--text-faint`, без анимации.
4. Подписка на аудио только при `playing && visible` (иначе 0 % CPU).

## Критерии приёмки

- AC-1 Полосы останавливаются при паузе.
- AC-2 Пустое состояние без ошибок в консоли.
- AC-3 CPU ≤ 0.3 % при выключенной музыке.

## Тест-план

Ручной + счётчик подписок на аудио.

## Риски

Без аудиозахвата (выключен пользователем) визуализатор не работает →
показывать «Включите аудиореакцию в настройках» в поповере.
