# T-0705 — Плеер

## 1. Цель

Управлять музыкой, не переключаясь в плеер. Данные — от системного медиа-контрола.

## 2. Источник данных

- `GlobalSystemMediaTransportControlsSessionManager` (WinRT): текущий трек,
  исполнитель, альбом, обложка, состояние, позиция.
- Управление: play/pause, next/prev, seek (где поддерживается).
- Работает для Spotify, Яндекс.Музыки, браузеров (Chromium/Edge), foobar2000 и т.д.
- Обновления по событию `MediaPropertiesChanged`/`PlaybackInfoChanged`,
  плюс опрос позиции раз в секунду (только при видимом виджете).

## 3. UI

- Обложка 44×44 (скругление 8), название (`t-body`), исполнитель (`t-caption`).
- Прогресс — 2 px линия, без «ползунка» (перемотка по клику — опция).
- Транспорт: три иконки 19 px, `play/pause` — акцент.
- Визуализатор: 22 полосы из `scene.audio_frame` (P6.4), 30 fps, только при
  активном воспроизведении.
- Если нет активной сессии — «Ничего не играет» + приглушённая иконка.

## 5. Критерии приёмки

- **AC-1** Трек и обложка совпадают с плеером ≤ 1 с после переключения.
- **AC-2** Транспорт работает для Spotify, Edge, foobar2000 (проверено вручную).
- **AC-3** Нет сессии → аккуратное пустое состояние, без ошибок.
- **AC-4** Визуализатор останавливается при паузе (0 fps).
- **AC-5** CPU ≤ 0.3 % в покое.

на 0».
