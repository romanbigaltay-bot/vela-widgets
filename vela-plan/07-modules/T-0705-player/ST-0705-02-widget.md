# ST-0705-02 — Виджет плеера

## Цель

Компактный блок, который не отвлекает.

## Реализация

1. Обложка: `<img>` 44×44, `border-radius: 8`, при отсутствии — плашка с иконкой.
2. Текст: название (ellipsis), исполнитель (`--text-dim`).
3. Прогресс: 2 px, `--track` + `--accent`; клик — перемотка (опция, только если
   `duration_ms > 0`).
4. Транспорт: prev/play(next) иконки 19 px; play/pause меняет иконку по состоянию.
5. Время: `1:48 / 4:52`, tabular, `--text-faint`.

## Критерии приёмки

- AC-1 Длинные названия не ломают вёрстку (ellipsis).
- AC-2 Иконка play/pause синхронна с реальным состоянием.
- AC-3 Прогресс не «дёргается» при обновлении раз в секунду.

## Тест-план

TC-0705-03 + скриншоты.

## Риски

Обложка может быть огромной (несколько МБ) → ресайз в Rust до 88×88 перед отправкой.
