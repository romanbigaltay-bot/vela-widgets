# P7 — Экосистема модулей

**Цель этапа:** заполнить рабочий стол полезным. Здесь пять модулей и два
сквозных инструмента (палитра команд, буфер обмена), которые превращают
техническую демку в продукт.

**Оценка:** 7 дней. **Gate:** G7.

| ID | Задача | Приоритет | Дней | Владелец | Зависит от |
|---|---|---|---|---|---|
| T-0701 | Календарь (ICS, события, счётчик) | P0 | 1.5 | ui+rust | P4 |
| T-0702 | Системный монитор | P0 | 1.0 | rust+ui | P4 |
| T-0703 | Погода и качество воздуха | P1 | 1.0 | ui+rust | P4 |
| T-0704 | Cron / планировщик | P0 | 1.5 | rust+ui | P4, T-0204 |
| T-0705 | Плеер (now playing + визуализатор) | P1 | 1.0 | rust+ui | P4, T-0604 |
| T-0706 | Палитра команд, буфер обмена, тикер | P0 | 1.0 | ui+rust | P4 |

## Порядок

```
T-0702 ──┐
T-0703 ──┼──► G7
T-0701 ──┤
T-0704 ──┤
T-0705 ──┤
T-0706 ──┘
```
Модули независимы (это проверка рантайма из P4) и делаются параллельно.
T-0704 (cron) требует `LifecycleService` из T-0204-03 для catch-up.

## Критерии выхода (G7)

- [ ] Календарь показывает события из ICS и локальные, счётчик до встречи.
- [ ] Системный монитор: CPU/GPU/RAM/диск/сеть, живые графики, ≤ 2 % CPU.
- [ ] Погода: кэш 30 мин, офлайн — последние данные с пометкой, без спама сети.
- [ ] Cron: визуальный редактор, срабатывания по расписанию, лог, catch-up.
- [ ] Плеер: now playing от системного медиа-контрола, транспорт, визуализатор.
- [ ] Палитра: поиск по заметкам, действиям, приложениям; буфер обмена с историей.

## Риски этапа

- OQ-02 (шифрование истории буфера) — решается до закрытия T-0706.
- Все сетевые модули обязаны работать офлайн (последние данные), иначе продукт
  «ломается» без интернета.
