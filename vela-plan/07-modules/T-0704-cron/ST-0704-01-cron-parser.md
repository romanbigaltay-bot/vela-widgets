# ST-0704-01 — Парсер cron

## Цель

Один парсер для Rust и для предпросмотра в UI (общая логика через `vela-cron`).

## Реализация

1. `vela-cron::parse(expr) -> CronSchedule`: 5 полей (мин, час, день, месяц, день недели),
   поддержка `*`, `*/n`, `a-b`, `a,b`, списков диапазонов, номеров дней недели 0–7.
2. `next_fire_at(schedule, from: DateTime<Tz>) -> DateTime<Tz>` — итеративный поиск
   по минутам с ограничением 4 года (защита от невозможных комбинаций).
3. Валидация: `31 февраля` невозможен → понятная ошибка «эта комбинация не
   встречается».
4. `describe(schedule) -> String` — человекочитаемое описание (ru/en).
5. Не поддерживаем `L`, `W`, `#` в v1 — явно отклонять с сообщением.

## Критерии приёмки

- AC-1 30 выражений: `next_fire_at` совпадает с эталоном (включая переход на летнее время).
- AC-2 Невозможная комбинация даёт ошибку за ≤ 100 мс.
- AC-3 `describe` понятен без знания cron (проверка на 5 пользователях-разработчиках).

## Тест-план

TC-0704-01 + тест DST (переход 2:00→3:00).

## Риски

DST может дать 0 или 2 срабатывания в сутки → политика: не срабатывать дважды,
пропущенные — по catch-up.
