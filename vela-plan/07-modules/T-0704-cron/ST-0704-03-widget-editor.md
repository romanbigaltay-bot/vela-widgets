# ST-0704-03 — Виджет планировщика

## Цель

Планировщик, которым не страшно пользоваться.

## Реализация

1. Список: время (`09:00`), описание действия, тумблер; выключенные — приглушены
   и зачёркнуты.
2. Редактор в поповере: cron-выражение + предпросмотр «следующее: пн, 09:00»;
   выбор действия из списка + параметры по схеме.
3. Валидация на вводе: невозможные комбинации — красная подсказка.
4. Лог: последние 20 выполнений (время, статус, длительность), `failed` — `--danger`.
5. `run.command` — диалог подтверждения с показом полного пути и предупреждением.

## Критерии приёмки

- AC-1 Предпросмотр совпадает с реальным срабатыванием (тест).
- AC-2 Невозможное выражение не сохраняется.
- AC-3 Лог показывает `failed` с причиной.

## Тест-план

TC-0704-04 + сверка предпросмотра с бэкендом для 10 выражений.

## Риски

Cron-выражение пугает пользователей → дефолтные пресеты («каждый день в 9:00»,
«по будням», «каждый час»).
