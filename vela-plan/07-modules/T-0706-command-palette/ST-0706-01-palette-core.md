# ST-0706-01 — Ядро палитры

## Цель

Найти нужное за 2–3 нажатия, без запоминания команд.

## Реализация

1. `palette/sources/`: `commands`, `notes`, `apps`, `settings`, `widgets` —
   единый интерфейс `Source { id, search(q): Promise<Item[]> }`.
2. `Item { id, title, subtitle, group, hotkey?, run() }`.
3. Ранжирование: `score = exact*100 + prefix*50 + substring*20 + freq*0.5 + recency*0.3`.
4. Дебаунс ввода 120 мс, отмена устаревших запросов (`AbortController`).
5. Группировка и заголовки групп; `Tab` — переход между группами.

## Критерии приёмки

- AC-1 Поиск по 500 заметкам ≤ 30 мс.
- AC-2 Топ-3 корректен для 20 тестовых запросов.
- AC-3 Устаревшие результаты не перезаписывают новые.

## Тест-план

TC-0706-01, TC-0706-03.

## Риски

Индексация приложений «Пуск» медленная → асинхронно, после открытия палитры
(сначала команды, потом приложения).
