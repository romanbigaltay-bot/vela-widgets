# T-0706 — Палитра и буфер

## 1. Цель

Один вход ко всему: «Ctrl+Alt+K» → найти заметку, запустить действие, открыть
приложение. Плюс история буфера обмена, чтобы не терять скопированное.

## 2. Палитра

- Источники: команды приложения, действия виджетов, заметки (поиск), приложения
  (из меню «Пуск» через `IShellWindows`/`SHGetKnownFolderItem`), настройки
  (переход к разделу).
- Ранжирование: точное совпадение > префикс > подстрока; частота использования
  как буст; недавние сверху.
- Клавиатура: `↑↓`, `Enter`, `Esc`, `Tab` — группа, `Ctrl+Enter` — вторичное
  действие (например, «открыть в новом»).
- Показ горячей клавиши рядом с каждым пунктом (для обучаемости).

## 3. Буфер обмена

- История: последние 50 текстов и 10 изображений, `Win+V`-подобно, но в нашей
  палитре (`Ctrl+Alt+V`).
- Хранение: только в памяти сессии по умолчанию; опция «сохранять между сессиями»
  (тогда в БД, с предупреждением о приватности). OQ-02.
- Исключения: приложения с `CanIncludeInClipboardHistory = false` (пароли) —
  не сохранять.

## 4. Тикер (P2)

- Одна строка в доке: RSS/курсы/стоимость, ротация каждые 8 с.
- Источник — настройка, только по явному добавлению.

## 6. Критерии приёмки

- **AC-1** Палитра открывается ≤ 120 мс, поиск по 500 заметкам ≤ 30 мс.
- **AC-2** Релевантность: запрос «зам» находит «Заметка: замеры» в топ-3.
- **AC-3** Буфер не сохраняет пароли (проверка с менеджером паролей).
- **AC-4** Вставка из истории возвращает исходный формат (текст/изображение).
- **AC-5** Тикер не делает запросов чаще, чем раз в 5 мин.

при старте, обновлять при `WM_SETTINGCHANGE`.
