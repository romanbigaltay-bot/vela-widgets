# ST-0706-02 — Буфер обмена

## Цель

Не терять скопированное и не хранить лишнее.

## Реализация

1. `AddClipboardFormatListener` на скрытом окне → `WM_CLIPBOARDUPDATE` →
   чтение форматов (`CF_UNICODETEXT`, `CF_DIB`/`PNG`).
2. Фильтры: пропускать, если `GetClipboardSequenceNumber` не изменился;
   если источник помечен как приватный (эвристика: имя процесса в списке
   менеджеров паролей) — не сохранять; лимит 50 текстов/10 изображений.
3. Хранение: память сессии по умолчанию; опция — БД (с предупреждением).
4. Вставка: `SetClipboardData` из выбранной записи, восстановление формата.
5. Дедупликация: одинаковый текст не добавляется повторно (перемещается вверх).

## Критерии приёмки

- AC-1 50 записей, старые вытесняются.
- AC-2 Пароли не попадают в историю (тест с KeePass-подобным окном).
- AC-3 Вставка изображения сохраняет формат (проверка в Paint).
- AC-4 Дедупликация работает.

## Тест-план

TC-0706-02.

## Риски

Слушатель буфера — потенциальный конфликт с другими менеджерами (Windows `Win+V`)
→ работать независимо, без блокировки.
