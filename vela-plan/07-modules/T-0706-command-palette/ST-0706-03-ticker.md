# ST-0706-03 — Тикер

## Цель

Одна строка информации, которая не мешает.

## Реализация

1. Источники v1: RSS (заголовки), погода (температура), курс валют (если настроен),
   курс крипты (опционально).
2. Ротация каждые 8 с, `transition: opacity` 300 мс между элементами.
3. Обновление данных: не чаще 1 раза в 5 мин, кэш.
4. Ошибка сети → последние данные с приглушением.
5. Настройка: включить/выключить, список источников, порядок.

## Критерии приёмки

- AC-1 Ротация без «прыжка» ширины (min-width, ellipsis).
- AC-2 Не более 1 запроса в 5 мин на источник.
- AC-3 Офлайн — приглушённые последние данные.

## Тест-план

Ручной + счётчик запросов.

## Риски

Тикер в доке может отвлекать → по умолчанию выключен.
