# T-0701 — Календарь

## 1. Цель

Виджет, отвечающий на два вопроса: «что сегодня» и «сколько до встречи».

## 2. Функциональность

- Месячная сетка, сегодня выделен, дни с событиями — точка.
- Список ближайших событий (до 5) с временем и названием.
- Счётчик до ближайшего события («через 12 мин»), обновление раз в минуту.
- Источники: локальные события, ICS-подписки (Google/Outlook по URL, только
  чтение), `ics`-файл с диска.
- Клик по дню — список событий дня в поповере.
- Настройки: первый день недели, показывать ли прошедшие, какие календари включены.

## 3. Данные и синхронизация

- Таблица `calendar_sources {id, name, kind: 'local'|'ics_url'|'ics_file', url, color, enabled, last_sync}`.
- Таблица `calendar_events {uid, source_id, start, end, all_day, title, location, rrule}`.
- Синхронизация: раз в 30 мин, только при включённом источнике, `If-Modified-Since`,
  таймаут 10 с, при ошибке — последние данные с пометкой «устарело».
- Развёртывание `RRULE`: поддержка `FREQ=DAILY|WEEKLY|MONTHLY`, `COUNT`, `UNTIL`,
  `BYDAY` — рабочие события; остальное игнорируется с логом.
- Никакой двусторонней синхронизации в v1.

## 5. Критерии приёмки

- **AC-1** ICS с 500 событиями парсится ≤ 300 мс.
- **AC-2** Офлайн: показывает последние данные с пометкой «обновлено 2 ч назад».
- **AC-3** Счётчик точен: «через 12 мин» соответствует реальному времени ± 1 мин.
- **AC-4** Повторяющиеся события (еженедельные) отображаются корректно.
- **AC-5** Сетка не ломается при 6 неделях в месяце (високосные, длинные месяцы).

## 7. Риски

ICS от Google содержит `VTIMEZONE` со сложными правилами → использовать
`tz` из системы по `TZID`, с фолбэком на UTC.
