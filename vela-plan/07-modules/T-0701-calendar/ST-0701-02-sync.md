# ST-0701-02 — Синхронизация

## Цель

Обновлять данные без спама сети и без «зависаний» при плохом интернете.

## Реализация

1. `calendar::sync_all()`: последовательно по источникам, таймаут 10 с,
   `If-Modified-Since` по `last_sync`.
2. Планировщик: раз в 30 мин (через токио-интервал в фоне), только при
   `settings.calendar.auto_sync`.
3. Ошибка → `last_error` в источнике, данные не трогаются, событие
   `calendar.sync_failed`.
4. Файл с диска: чтение по `mtime`, без сети.
5. Приватность: URL хранится локально, запросы без cookies, только GET.

## Критерии приёмки

- AC-1 Офлайн → последние данные, пометка «устарело».
- AC-2 304 Not Modified не перезаписывает БД.
- AC-3 Таймаут 10 с, приложение не ждёт сеть при старте (синк в фоне).

## Тест-план

TC-0701-04 (мок-сервер), тест таймаута.

## Риски

Пользователь может вставить приватную ссылку — не логировать полный URL
(только домен).
