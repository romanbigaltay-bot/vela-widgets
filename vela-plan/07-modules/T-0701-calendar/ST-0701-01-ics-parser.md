# ST-0701-01 — ICS-парсер

## Цель

Читать чужие календари без сюрпризов: кодировки, переносы строк, повторы.

## Реализация

1. Таблицы `calendar_sources`, `calendar_events` (миграция `0002_calendar.sql`).
2. Парсер: `ical`-подобный собственный (или крейт `ical`), обработка:
   `folded lines` (перенос с пробелом), `
`/`
`, `ESCAPED` символы,
   `DTSTART;TZID=`, `DTSTART;VALUE=DATE` (all-day).
3. `RRULE`: `FREQ`, `INTERVAL`, `COUNT`, `UNTIL`, `BYDAY`; разворачивание в
   горизонте ±1 год при синхронизации, не бесконечно.
4. Ошибки: битый блок пропускается с логом, остальные события читаются.
5. Индексы: `(start)`, `(source_id, start)`.

## Критерии приёмки

- AC-1 500 событий ≤ 300 мс.
- AC-2 8 фикстур (Google/Outlook/Apple) парсятся без исключений.
- AC-3 Битый блок не ломает остальные события.

## Тест-план

TC-0701-01, TC-0701-02.

## Риски

Некоторые календари отдают `TZID` с нестандартными именами → маппинг на
системный `Windows`-TZ, при неудаче — UTC с пометкой.
