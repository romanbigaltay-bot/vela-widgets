# ST-0701-03 — Виджет календаря

## Цель

Компактно, читаемо, без «календаря из 2010».

## Реализация

1. Сетка: `Пн–Вс` (настройка), 6 строк максимум, дни других месяцев — `--text-faint`
   и opacity .35.
2. Сегодня: круг `--accent` 20 % + текст `--text`; день с событием — точка 2 px
   под цифрой.
3. Ближайшие события: время `tabular`, название обрезается `ellipsis`, до 5.
4. Счётчик до ближайшего: `--accent`, обновление раз в минуту (`ctx.clock` 60 000).
5. Поповер по клику на день: список событий, закрытие по `Esc`.

## Критерии приёмки

- AC-1 Сетка корректна для 12 месяцев 2026–2028.
- AC-2 Точки событий соответствуют данным.
- AC-3 Поповер не выходит за пределы экрана (позиционирование).

## Тест-план

TC-0701-03 + визуальные скриншоты.

## Риски

Разные локали начала недели → настройка + `Intl.Locale.weekInfo` как дефолт.
