# ST-0702-01 — Сбор метрик

## Цель

Все метрики — одним опросом, с предсказуемой стоимостью.

## Реализация

1. `sysmon::collector` в отдельном потоке: набор счётчиков PDH (`PdhOpenQuery`,
   `PdhCollectQueryData`), WMI-запрос температуры (опционально, лениво).
2. Модель `SystemMetrics { cpu, mem_used, mem_total, gpu: Option<f32>, disk_free,
   disk_io, net_rx, net_tx, temp: Option<f32>, top: Vec<(String, f32)> }`.
3. Публикация `system.metrics` раз в 2 с (только если есть подписчики).
4. Подписка: виджеты регистрируют интерес (`system.subscribe`); нет подписчиков —
   нет опроса (0 % CPU).
5. Ошибки счётчиков — `None`, не 0.

## Критерии приёмки

- AC-1 CPU сбора ≤ 0.4 %.
- AC-2 Нет опроса без подписчиков.
- AC-3 GPU на неподдерживаемом драйвере → `None`, без ошибок.

## Тест-план

TC-0702-01, TC-0702-02.

## Риски

WMI-запросы медленные (100+ мс) → только раз в 30 с и в отдельном потоке,
никогда в главном.
