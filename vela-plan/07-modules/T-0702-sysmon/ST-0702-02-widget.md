# ST-0702-02 — Виджет

## Цель

Считывается за полсекунды, не выглядит как дашборд.

## Реализация

1. Строка: `название` (`t-caption`) — значение (`t-body`, tabular) — полоса 2 px.
2. Полоса: `--track` фон, `--accent` заполнение; `--warn` > 85 %, `--danger` > 95 %.
3. Sparkline: SVG polyline 60 точек, 1 px, `--accent` opacity .5; включается
   настройкой; буфер кольцевой.
4. Анимация изменения ширины — 200 мс `ease`, не «прыжок».
5. При `null` метрике — прочерк и приглушённая строка.

## Критерии приёмки

- AC-1 Значения не «дёргаются» (tabular + фиксированная ширина).
- AC-2 85/95 % пороги дают цвет, остальное — акцент.
- AC-3 Sparkline не растёт по памяти (кольцевой буфер).

## Тест-план

Визуальные скриншоты 3 состояний; юнит кольцевого буфера.

## Риски

Частое обновление (2 с) + transition могут «залипать» → transition только при
изменении > 1 п.п.
