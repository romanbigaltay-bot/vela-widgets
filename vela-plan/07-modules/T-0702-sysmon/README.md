# T-0702 — Системный монитор

## 1. Цель

Понятная картина «что происходит с машиной» без диспетчера задач: CPU, GPU,
RAM, диск, сеть, температуры. Дёшево по CPU.

## 2. Данные

| Метрика | Источник | Частота |
|---|---|---|
| CPU % | `PDH` счётчик `\Processor(_Total)\% Processor Time` | 2 с |
| RAM | `GlobalMemoryStatusEx` | 2 с |
| GPU % | `PDH` `\GPU Engine(*)\Utilization Percentage` (сумма) | 2 с |
| Диск (занято) | `GetDiskFreeSpaceExW` | 30 с |
| Диск I/O | `PDH` `\LogicalDisk(_Total)\Disk Bytes/sec` | 5 с |
| Сеть | `GetIfTable2` (сумма по активным) | 5 с |
| Температура | WMI `MSAcpi_ThermalZoneTemperature` (если доступна) | 30 с |
| Топ-процессы | `PDH` по `\Process(*)\...` (топ-3 по CPU) | 10 с |

- GPU-метрика доступна не на всех драйверах → скрывать строку, а не показывать 0.
- Все счётчики читаются в одном фоновом потоке, один опрос на все виджеты
  (не по одному на экземпляр).

## 3. UI

- Пять строк: название, процент (tabular), тонкая полоса прогресса (2 px).
- Полоса меняет цвет только при > 85 % (`--warn`) и > 95 % (`--danger`) —
  не «радуга».
- Sparkline последних 60 значений (30 px высотой) — опция.
- Клик — раскрыть топ-процессы (поповер).

## 4. Состав подзадач

| ID | Подзадача | Дней |
|---|---|---|
| ST-0702-01 | Сбор метрик (PDH, WMI) в фоне | 0.5 |
| ST-0702-02 | Виджет: строки, полосы, sparkline | 0.3 |
| ST-0702-03 | Топ-процессы и обработка недоступных метрик | 0.2 |

## 5. Критерии приёмки

- **AC-1** CPU виджета ≤ 0.6 %, GPU ≤ 0.3 %.
- **AC-2** Отсутствие GPU-счётчика → строка скрыта, остальное работает.
- **AC-3** Значения совпадают с диспетчером задач ± 3 п.п.
- **AC-4** Один опрос на все экземпляры виджета (счётчик PDH-запросов).
- **AC-5** При `occluded` опрос останавливается.

## 6. Тест-план

| ID | Проверка |
|---|---|
| TC-0702-01 | Интеграция: чтение метрик, сравнение с эталоном (фикстура) |
| TC-0702-02 | Тест недоступной метрики (мок PDH-ошибки) |
| TC-0702-03 | Замер CPU виджета за 60 с |

## 7. Риски

`PDH` требует инициализации на поток; при перезапуске счётчиков (драйвер GPU)
нужна переинициализация — обработка ошибки `PDH_CSTATUS_INVALID_DATA`.
