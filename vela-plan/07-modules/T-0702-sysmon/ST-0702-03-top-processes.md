# ST-0702-03 — Топ-процессы

## Цель

Ответ на «что жрёт CPU» без открытия диспетчера.

## Реализация

1. `PDH` по `\Process(*)\% Processor Time` — топ-3 по сумме за интервал.
2. Имена процессов: `GetProcessImageFileNameW` → короткое имя + PID.
3. Поповер: 3 строки, имя, PID, %, кнопка «Открыть диспетчер» (опция).
4. Обновление раз в 10 с, только когда поповер открыт (иначе не собираем).

## Критерии приёмки

- AC-1 Топ-3 совпадает с диспетчером ± 1 позиция.
- AC-2 Сбор только при открытом поповере.
- AC-3 Нет падений при завершении процесса между опросами.

## Тест-план

Ручной + тест с «убитым» процессом.

## Риски

Имена могут содержать нелатинские символы — использовать `W`-API и UTF-16
корректно.
