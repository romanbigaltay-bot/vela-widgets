# T-0703 — Погода

## 1. Цель

Цифры, которые нужны перед выходом: температура, ощущается, ветер, осадки на
час вперёд. Без картинок с солнышком.

## 2. Решение по данным

- Провайдер: Open-Meteo (без ключа, без регистрации, CC-BY) — соответствует
  принципу «никакой телеметрии по умолчанию»: запрос только за погодой, без
  идентификаторов.
- Геолокация: не через GPS, а по настройке «город» (поиск по названию через
  их же geocoding) — приватнее и надёжнее.
- Кэш: 30 минут; при отсутствии сети — последние данные + «обновлено N назад».
- Запрос: 1 раз в 30 мин, только при видимом виджете.

## 3. Отображение

- Крупно: температура (`t-display`), рядом «ощущается как».
- Строка: ветер (м/с + направление стрелкой), влажность, осадки мм/ч.
- Мини-график на 8 часов (тонкая линия, `--accent`).
- Иконка — не эмодзи, а монохромный SVG-набор (6 состояний), цвет `--text-dim`.

## 5. Критерии приёмки

- **AC-1** Первый ответ ≤ 1.5 с при хорошей сети; при ошибке — скелет, не пусто.
- **AC-2** Офлайн → последние данные + пометка «обновлено 2 ч назад».
- **AC-3** Не более 2 запросов в час (счётчик в логе).
- **AC-4** Единицы измерения переключаются (°C/°F, м/с/км/ч).

## 7. Риски

Внешний API может измениться/быть недоступен → клиент с версией API и понятной
ошибкой, возможность сменить провайдера (интерфейс `WeatherProvider`).
