# ST-0703-03 — Город и настройки

## Цель

Смена города за два клика, без ввода координат.

## Реализация

1. Настройка `city` (название + lat/lon), поиск через geocoding API (тот же
   провайдер), топ-5 результатов.
2. Настройки: единицы, показывать график, показывать «ощущается».
3. Валидация: lat ∈ [-90, 90], lon ∈ [-180, 180].

## Критерии приёмки

- AC-1 Поиск «Москва» даёт корректный результат.
- AC-2 Невалидные координаты отклоняются.
- AC-3 Смена города обновляет данные сразу (сброс кэша).

## Тест-план

Ручной + юнит валидации.

## Риски

Дубли названий городов → показывать страну и регион в результатах.
