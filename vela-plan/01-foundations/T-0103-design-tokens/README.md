# T-0103 — Дизайн-токены, темы, ThemeService

## 1. Цель

Зафиксировать визуальный язык в коде до первой панели: цвет, типографика,
тени, стекло, движение. Любой компонент потом собирается только из токенов.

## 2. Состав токенов

| Группа | Токены |
|---|---|
| Поверхности | `--bg`, `--bg-elev`, `--panel`, `--panel-hi`, `--stroke`, `--stroke-hi` |
| Текст | `--text`, `--text-dim`, `--text-faint`, `--text-on-accent` |
| Акцент | `--accent`, `--accent-soft`, `--accent-glow` |
| Семантика | `--ok`, `--warn`, `--danger` (приглушены до 60 % сатурации) |
| Форма | `--radius-chip 4`, `--radius-inner 10`, `--radius-panel 16`, `--radius-pill 999` |
| Пространство | `--sp-1..--sp-9` (4→48, шаг 4) |
| Тень/свет | `--shadow`, `--inner`, `--glow` |
| Стекло | `--blur 28px`, `--glass-tint`, `--glass-noise` |
| Движение | `--ease`, `--dur-in 120ms`, `--dur-out 200ms` |

Значения — из работающего прототипа (`vela-canvas.html`), они уже проверены
по контрасту на реальных отрендеренных пикселях.

## 3. Решение по темам

- Тема = атрибут `data-theme="dark|light"` на `<html>`, два набора токенов.
- Светлая не инвертируется: подбирается отдельно (иначе серый «пластик»).
- Режим `system` подписывается на `prefers-color-scheme` через Rust-событие
  (WebView2 сообщает надёжнее, чем matchMedia при смене настроек ОС).
- Переключение — без вспышки: токены применяются до первого кадра
  (внедрённый `<style>` с темой из SQLite, до гидрации React).

## 4. Контраст (проверено, не на глаз)

| Токен | Тёмная | Светлая | Минимум |
|---|---|---|---|
| `--text` | 12.9:1 | 16.5:1 | 4.5 |
| `--text-dim` | 6.2:1 | 6.9:1 | 4.5 |
| `--text-faint` | 4.1:1 | 4.2:1 | 3.0 (только крупный/вспомогательный) |
| `--accent` | 5.9:1 | 4.0:1 | 3.0 (для текста — 4.5, поэтому на светлом только фон/иконки) |

Правило: `--text-faint` запрещён для текста меньше 13 px, несущего смысл.

## 6. Критерии приёмки

- **AC-1** Компонент без `var(--…)` в цветах не проходит ревью (линт на hex).
- **AC-2** Переключение темы не даёт вспышки белым (запись экрана 240 fps).
- **AC-3** Контраст всех текстовых токенов ≥ заявленного (автотест по вычисленным
  цветам из CSSOM).
- **AC-4** `prefers-reduced-motion` обнуляет все длительности.
- **AC-5** Светлая и тёмная темы сняты скриншотами в `visual/`.

## 8. Риски

- WebView2 не поддерживает `backdrop-filter` стабильно на всех GPU →
  стекло реализуется кастомно (P3), `backdrop-filter` — только фолбэк.
- Пользовательские обои меняют восприятие контраста → панели всегда имеют
  подложку `--panel` с достаточной непрозрачностью.
