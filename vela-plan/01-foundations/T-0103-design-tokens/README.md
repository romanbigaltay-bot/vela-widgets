## 1. Цель

Зафиксировать визуальный язык в коде до первой панели: цвет, типографика,
тени, стекло, движение. Любой компонент потом собирается только из токенов.

## 3. Решение по темам

- Фактическая тема — `data-theme="dark|light"` на `<html>`; выбранный режим
  хранится отдельно в `data-theme-mode="dark|light|system"`, иначе
  `data-theme="system"` не совпал бы ни с одним набором токенов.
- Светлая не инвертируется: подбирается отдельно (иначе серый «пластик»).
- В светлой теме текст на акцентной заливке белый (`--text-on-accent:
  #ffffff`); для AA акцент затемнён до `#4a68e0` (4.83:1). В тёмной теме
  остаётся чёрный текст: на светлом акценте он читается лучше.
- В P1 режим `system` слушает `prefers-color-scheme` через `matchMedia`,
  режим хранится в `localStorage.vela.theme`; `storage`-событие
  синхронизирует поверхности одного origin.
- В P2 источником истины станет SQLite: UI → типизированная команда →
  SQLite → событие `app.theme_changed`; `setThemeFromHost` уже готов принять
  фактическую тему, не подменяя выбранный режим. До появления транспорта
  объявлять команду «на будущее» запрещено.
- Переключение — без вспышки: режим и тема применяются inline-скриптом в
  `index.html` до загрузки бандла. Скрипт исполняется автотестом
  `theme-boot.test.ts`, а не просто ищется строкой в файле.

## 4. Контраст (по фактическим токенам, 2026-11-05)

| Токен | Тёмная | Светлая | Минимум |
|---|---|---|---|
| `--text` | 16.3:1 | 16.8:1 | 4.5 |
| `--text-dim` | 7.8:1 | 7.0:1 | 4.5 |
| `--text-faint` | 5.3:1 | 4.3:1 | 3.0 (только крупный/вспомогательный) |
| `--accent` | 7.5:1 | 4.5:1 | 3.0 (заливка, рамки, иконки) |
| `--accent-text` | 7.5:1 | 4.8:1 | 4.5 (текст и ссылки) |
| `--text-on-accent` | 7.5:1 | 4.8:1 | 4.5 |

Правило: `--text-faint` запрещён для текста меньше 13 px, несущего смысл.
Светлый `--accent` проходит AA впритык (4.51:1), поэтому для обычного текста
и ссылок остаётся более тёмный `--accent-text` (4.78:1).

## 8. Риски

- WebView2 не поддерживает `backdrop-filter` стабильно на всех GPU →
  стекло реализуется кастомно (P3), `backdrop-filter` — только фолбэк.
- Пользовательские обои меняют восприятие контраста → панели всегда имеют
  подложку `--panel` с достаточной непрозрачностью.
- `localStorage` в P1 — временный источник; при очистке данных WebView тема
  вернётся к системной. Это ожидаемо до переноса в SQLite в P2.
