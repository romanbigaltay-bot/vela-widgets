# Запись переключения темы 240 fps

**Файл:** `theme-switch-240fps.mp4` (2.3 МБ)
**Снято:** 2026-11-06
**Стенд:** Windows 11, Chrome в kiosk-режиме, `http://localhost:5173/_kit`,
Vite dev server. Переключение «Тёмная» → «Светлая» выполнялось через CDP
во время записи.

## Параметры файла

| Параметр | Значение |
|---|---|
| Кодек | H.264 (`libx264`, ultrafast, CRF 14) |
| Разрешение | 1920×1080 |
| Частота | 240 fps CFR (`r_frame_rate=240/1`, `avg_frame_rate=240/1`) |
| Кадров | 1200 |
| Длительность | 5.000 с |

## Метод проверки

Каждый кадр свёрнут в один пиксель (`scale=1:1:flags=area`) и переведён в
RGB24; для каждого кадра считался средний цвет. Белая вспышка дала бы кадр,
где все три канала близки к 255.

## Результат

| Метрика | Значение |
|---|---|
| Максимум среднего RGB | 243 / 241 / 245 (светлая тема) |
| Минимум среднего RGB | 15 / 13 / 17 (тёмная тема) |
| Кадров с R, G, B ≥ 252 | **0** |
| Кадров светлой темы (R ≥ 200) | 842 |
| Кадров тёмной темы (R < 100) | 326 |

Переходы: светлая → тёмная около кадров 390–448, тёмная → светлая около
кадров 728–768. Средний цвет меняется между значениями тем и ни в одном
кадре не превышает светлую тему. Белой вспышки нет.

## Ограничение стенда

Монитор работает на 60 Гц, поэтому 240 fps получены CFR-дублированием
исходных 60 Гц кадров: файл и проверка — 240 fps, но уникальных кадров
физически не больше 60 в секунду. Это ограничение железа, а не записи.
