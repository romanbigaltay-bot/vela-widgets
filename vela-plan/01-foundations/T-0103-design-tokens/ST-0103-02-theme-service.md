# ST-0103-02 — ThemeService

## Цель

Тема применяется до первого кадра, слушает систему, сохраняется в БД.

## Реализация

1. Инлайн-скрипт в `index.html` (до бандла): читает `localStorage.vela.theme`
   и ставит `data-theme` немедленно; при отсутствии — `prefers-color-scheme`.
2. `ThemeService`: `get()`, `set(mode)`, `toggle()`, `mode: 'dark'|'light'|'system'`,
   подписка на событие `app.theme_changed` от Rust (системная тема изменилась).
3. Синхронизация: UI → IPC `app.settings_set({theme})` → SQLite → событие во все
   поверхности (A/B/C), чтобы не было рассинхрона.
4. Смена темы — через `transition` только на `background-color/color` 200 мс;
   при `reduced-motion` — 0.

## Критерии приёмки

- AC-1 Холодный старт в тёмной теме не даёт белой вспышки (запись 240 fps).
- AC-2 Смена системной темы при `mode: 'system'` подхватывается за ≤ 300 мс.
- AC-3 Тема переживает перезапуск и распространяется на все поверхности.

## Тест-план

Vitest: мок `localStorage`, проверка вычисленного `data-theme`.
E2E: старт с сохранённой светлой темой — первый кадр светлый.

## Риски

Инлайн-скрипт легко «потерять» при рефакторинге `index.html` — тест E2E
на первый кадр обязателен.
