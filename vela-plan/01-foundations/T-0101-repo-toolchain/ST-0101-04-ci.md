# ST-0101-04 — CI-пайплайн и скрипты запуска

## Цель

Пайплайн из `05-testing.md`, который на пустом проекте проходит за < 5 мин.

## Реализация

1. Корневой `.github/workflows/ci.yml`: GitHub Actions читает workflow только
   из корня репозитория, поэтому пути указывают на `vela-app`.
   - `rust`: fmt, clippy, test, arch-check;
   - `coverage`: `cargo llvm-cov --fail-under-lines 60` (D-17);
   - `ui`: typecheck, lint, format, test;
   - `ipc-contracts`: `pnpm ipc:check`.
2. Кэш: `Swatinem/rust-cache`, `pnpm/action-setup`; lockfile —
   `vela-app/ui/pnpm-lock.yaml`.
3. Артефакты: в P1 доступны логи job'ов. Скриншоты visual-тестов появятся
   вместе с окном в G2+.
4. Скрипты в `package.json`: `check`, `dev`, `build`, `ipc:gen`, `ipc:check`.
   `tauri:dev` появится в P2; `bench` — в T-0802 (P8).

## Критерии приёмки

- AC-1 CI зелёный на `main` после мержа этапа.
- AC-2 Полный прогон ≤ 5 мин при тёплом кэше.
- AC-3 Красный тест даёт ссылку на артефакт с логом в PR-комментарии.

AC-1 и AC-2 подтверждены 2026-11-06: run 42152167354 на `main` зелёный,
полный прогон 1 мин 46 с (порог 5 мин). AC-3 (красный тест и ссылка на
артефакт в PR-комментарии) не проверен, поэтому статус — `in-progress`.

## Тест-план

Пуш с намеренно падающим тестом → CI красный, артефакт доступен.

## Риски

Сборка Tauri на Windows-раннере медленная; при > 8 мин — разделить build и test
на разные job'ы с передачей артефакта.
