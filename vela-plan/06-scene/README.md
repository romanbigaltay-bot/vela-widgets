# P6 — Живой фон

**Цель этапа:** фон перестаёт быть картинкой и становится сценой: фото, видео,
2D/3D, аудиореакция. С правилом «сначала батарея и fps, потом красота».

**Оценка:** 9 дней. **Gate:** G6.

| ID | Задача | Приоритет | Дней | Владелец | Зависит от |
|---|---|---|---|---|---|
| T-0601 | Движок сцены: декларативные слои, рендер, качество | P0 | 2.5 | ui | P2, T-0304 |
| T-0602 | Фото и видео-фон | P0 | 2.0 | ui | T-0601 |
| T-0603 | 2D/3D сцена (шейдеры, параллакс) | P0 | 2.5 | ui | T-0601 |
| T-0604 | Аудиореакция и игра-фон (каркас) | P1 | 1.0 | ui+rust | T-0603 |
| T-0605 | Энергополитика сцены | P0 | 1.0 | rust+ui | T-0602 |

## Порядок

```
T-0601 ──┬──► T-0602 ──┬──► T-0605 ──┐
         └──► T-0603 ──┴──► T-0604 ──┴──► G6
```

## Критерии выхода (G6)

- [ ] Фото-фон: локальные файлы + папка-слайдшоу, кроссфейд.
- [ ] Видео-фон: аппаратное декодирование, зацикливание, без звука.
- [ ] 3D-сцена: параллакс за курсором, 60 fps на 1440p среднего GPU.
- [ ] Аудиореакция: 20 полос, реакция без «мигания», CPU ≤ 4 %.
- [ ] Все сцены: пауза при fullscreen, батарее < 25 %, lock, suspend.
- [ ] Blur mirror обновляется от сцены (согласовано с P3).
- [ ] Переключение сцен ≤ 450 мс без белой вспышки.
