# ST-0604-02 — Реакция

## Цель

Реакция на звук, которая выглядит живой, но не «мигает как светомузыка».

## Реализация

1. Uniform `uBands[8]` в шейдерные сцены; сглаживание `lerp(prev, cur, 0.25)`
   для плавности + `attack 0.4 / release 0.1` (быстрый вход, медленный спад).
2. Визуализатор виджета — 32 полосы, CSS-высота, обновление 30 fps.
3. Отключение при `occluded`/`suspended`: захват останавливается, полосы — нули.
4. Параметр `audio.intensity` (0.5–2.0) в настройках сцены.

## Критерии приёмки

- AC-1 Реакция не мигает (плавность на записи 60 fps).
- AC-2 Захват останавливается при невидимости (0 % CPU на audio).
- AC-3 Интенсивность влияет предсказуемо.

## Тест-план

Визуальная проверка на записи + счётчик вызовов захвата.

## Риски

Агрессивное сглаживание «съедает» динамику → прослушивание/просмотр на реальной
музыке перед фиксацией констант.
