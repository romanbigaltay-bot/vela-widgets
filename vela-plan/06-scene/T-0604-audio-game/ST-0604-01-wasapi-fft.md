# ST-0604-01 — Аудиозахват

## Цель

Спектр системного звука дешёво и без задержек.

## Реализация

1. `audio::loopback`: WASAPI shared mode, устройство по умолчанию (`eRender`),
   формат — `f32`/`i16` конвертируется в `f32`.
2. Буфер 1024 сэмпла, окно Ханна, FFT (`rustfft`), 8 полос (логарифмическая
   шкала 20 Гц – 16 кГц), нормализация в 0..1 с `sqrt`.
3. Публикация `scene.audio_frame { bands: [f32;8] }` не чаще 30 fps,
   только при активной подписке.
4. Смена устройства: подписка на `IMMNotificationClient` → пересоздание клиента.
5. Тишина/нет устройства → нули, без ошибок.

## Критерии приёмки

- AC-1 CPU ≤ 1.5 %.
- AC-2 Задержка ≤ 60 мс.
- AC-3 Смена устройства не роняет захват.

## Тест-план

TC-0604-01, TC-0604-02.

## Риски

Loopback недоступен для exclusive-mode приложений → документировать как
известное ограничение.
