# ST-0604-03 — Каркас игры

## Цель

Доказать, что интерактивная сцена технически возможна, не строя игру.

## Реализация

1. `scene/game/contract.ts`: `SceneGame { init(canvas, api), frame(dt), pointer(e), pause() }`.
2. Ввод: B ловит pointer-события в `pass`-режиме? Нет — в `edit`/`locked` на
   «горячих» зонах; для игры предусмотрен режим «сцена интерактивна», когда B
   отправляет события в A через `scene.pointer {x, y, type}` (координаты в мировых
   пикселях A).
3. Демо-игра: 200 частиц, клик — импульс отталкивания. Доказывает цикл.
4. Бюджет: 30 fps, пауза при невидимости, стоп при `pass`.
5. Документировать ограничения (нет прямого DOM, нет сети, нет fs).

## Критерии приёмки

- AC-1 Клик в мировых координатах попадает в ожидаемую точку при `scale` 0.5/1/2.
- AC-2 Игра стоит при `occluded` (0 fps).
- AC-3 Демо-игра не влияет на fps остальных элементов.

## Тест-план

TC-0604-03 + тест координат на трёх масштабах.

## Риски

Задержка IPC на ввод (2–4 мс) делает быстрые игры неудобными — это ожидаемое
ограничение, зафиксировать в документации, не обещать «игры вообще».
