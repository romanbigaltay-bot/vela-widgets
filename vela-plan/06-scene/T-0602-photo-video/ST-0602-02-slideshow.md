# ST-0602-02 — Слайдшоу

## Цель

Фон меняется сам, не мешая и не «дёргая» стекло.

## Реализация

1. Источник-папка: рекурсивный список изображений (jpg/png/webp/avif), сортировка
   по имени/дате (опция), лимит 500 файлов для списка.
2. Интервал 30 с – 24 ч; `fade` 800 мс через механизм T-0601-04.
3. Переход не раньше, чем предыдущий кадр загружен (без мигания).
4. При `occluded`/`suspended` таймер стоит; при возврате — не «догоняет» пачкой.
5. Случайный порядок без повторов в текущем цикле (shuffle-bag).

## Критерии приёмки

- AC-1 100 переходов: нет роста памяти.
- AC-2 Переход не происходит, если следующий файл не загрузился.
- AC-3 После сна не происходит «каскад» переходов.

## Тест-план

TC-0602-04 + ускоренный тест с интервалом 1 с (dev-режим).

## Риски

Папка на сетевом диске → медленная загрузка; показывать текущую сцену до
готовности новой.
