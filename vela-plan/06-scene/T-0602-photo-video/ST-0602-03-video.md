# ST-0602-03 — Видео

## Цель

Видео как обои, а не как плеер: тихо, экономно, останавливается, когда не нужно.

## Реализация

1. `<video>` (muted, loop, playsInline, preload auto) + текстура в WebGL
   (`texImage2D` по `requestVideoFrameCallback`, не по rAF — точнее и дешевле).
2. Пауза/возобновление по `LifecycleService` и `power_state`, `fullscreen` детект.
3. Скрытие элемента при `occluded` — `video.pause()`, чтобы не декодировать зря.
4. Ошибки: `error.code` → понятный текст (`MEDIA_ERR_SRC_NOT_SUPPORTED` → «кодек
   не поддерживается, показан первый кадр»).
5. Детект программного декодирования: CPU > 15 % при 1080p → лог и тост
   (один раз за сессию).
6. Первый кадр как постер: `poster` из кадра 0, чтобы не было чёрного мигания.

## Критерии приёмки

- AC-1 CPU ≤ 4 %, GPU ≤ 25 % на 1080p 30 fps.
- AC-2 Пауза ≤ 300 мс после fullscreen.
- AC-3 Ошибка кодека → постер + тост, не чёрный экран.
- AC-4 10 минут без рывков (счётчик пропущенных кадров < 5).

## Тест-план

TC-0602-02, TC-0602-03.

## Риски

`requestVideoFrameCallback` может не поддерживаться в старых WebView2 →
фолбэк на `rAF` с проверкой `readyState`.
