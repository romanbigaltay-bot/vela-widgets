# T-0602 — Фото и видео

## 1. Цель

Личные фото и видео как фон: без задержек, без звука, без расхода батареи
как у видеоплеера.

## 2. Фото

- Источники: файл, папка (слайдшоу), встроенные градиентные сцены.
- Форматы: jpg, png, webp, avif; HEIC через системный декодер (опционально).
- Подгонка `cover`/`contain`, затемнение `vignette`, размытие фона (для «обоев
  из любого фото»).
- Слайдшоу: интервал 30 с – 24 ч, переход `fade` 800 мс, случайный порядок.
- Кэш миниатюр и подготовленных текстур (WebP в кэше) для мгновенной загрузки.

## 3. Видео

- Декодирование: `<video>` с `muted`, `loop`, `playsInline`, `preload="auto"`;
  аппаратное ускорение по умолчанию.
- Звука нет всегда — это фон.
- Пауза при: fullscreen-приложении, батарее < 25 %, lock, suspend, скрытии сцены.
- Потребление: цель ≤ 9 %/ч на батарее для 1080p H.264.
- Неподдерживаемый кодек → понятная ошибка и фолбэк на первый кадр как фото.

## 5. Критерии приёмки

- **AC-1** Первый кадр фото ≤ 200 мс после выбора.
- **AC-2** Видео 1080p: CPU ≤ 4 %, GPU ≤ 25 %, без рывков 10 минут.
- **AC-3** Неподдерживаемый файл → ошибка + фолбэк, не чёрный экран.
- **AC-4** Слайдшоу не накапливает память за 100 переходов.
- **AC-5** Пауза видео при fullscreen срабатывает ≤ 300 мс.

«программное декодирование» по CPU > 15 % и предупреждение.
