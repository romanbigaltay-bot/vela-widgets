# ST-0601-02 — Рендерер

## Цель

Один проход, слои, плавный параллакс, без утечек контекста.

## Реализация

1. `scene/gl/`: создание контекста (`alpha: false, antialias: false, powerPreference: 'high-performance'`),
   ресайз с учётом dpr-капа.
2. Программа на слой-тип: `photo` (текстура + cover-UV), `shader` (фрагментный
   fbm), `solid`.
3. Параллакс: uniform `uPointer` (сглаженный lerp 0.05), сдвиг UV на
   `pointer * depth * 0.02`.
4. Кадры: рендер только при изменении (время, курсор, смена слоя); при статичной
   сцене — стоп (важно для батареи).
5. Утечки: удаление текстур/программ при смене сцены; тест на 50 смен.

## Критерии приёмки

- AC-1 Статичная сцена: 0 fps после 2 с (кроме курсора).
- AC-2 Параллакс без рывков, задержка ≤ 1 кадр.
- AC-3 50 смен сцены: GPU-память стабильна (проверка через `WEBGL_debug_renderer_info`
  и счётчик текстур).

## Тест-план

TC-0601-03 + тест утечек.

## Риски

Потеря контекста (`webglcontextlost`) при смене драйвера/сна → пересоздание
с восстановлением состояния (обработчик обязателен).
