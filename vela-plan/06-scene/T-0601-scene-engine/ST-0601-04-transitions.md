# ST-0601-04 — Переходы

## Цель

Смена фона не выглядит как «переключение слайда» и не даёт белого кадра.

## Реализация

1. Двойной буфер таргетов: старая сцена рендерится в FBO A, новая в B,
   смешиваются по `uMix` (ease-in-out 400 мс).
2. Новая сцена начинает рендериться заранее (первый кадр) до начала фейда.
3. При `reduced-motion` — мгновенная смена.
4. Параллельно — crossfade для mirror (иначе стекло «дёрнется»).
5. Ошибка загрузки новой сцены → откат к прежней, тост.

## Критерии приёмки

- AC-1 Нет белого кадра в записи 60 fps при переходе фото→видео.
- AC-2 Mirror меняется синхронно (разница средних цветов ≤ 5 % в кадре перехода).
- AC-3 Ошибка → сцена не меняется, тост с причиной.

## Тест-план

TC-0601-04 + запись экрана на 240 fps для проверки белого кадра.

## Риски

Двойной рендер на слабом GPU просаживает fps на 400 мс → разрешить переход
без double-buffer на уровне качества 1 (мгновенная смена).
