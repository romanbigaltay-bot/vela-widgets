# ST-0601-03 — Качество

## Цель

Красиво на хорошем железе, терпимо на плохом, никогда — не «слайд-шоу».

## Реализация

1. `qualityLevel: 1|2|3`: разрешение рендера (0.75×/1.0×/1.5× CSS), октавы шума
   (3/4/5), dpr-кап (1.0/1.25/1.5).
2. Автодеградация: скользящее среднее fps за 3 с; < 45 → понизить уровень,
   > 58 стабильно 30 с → повысить (с гистерезисом 60 с).
3. Привязка к питанию: на батарее уровень ≤ 2; < 25 % — уровень 1 или пауза.
4. Ручная настройка `performance.scene_quality = auto|low|medium|high`.
5. Лог изменений уровня (dev) для отладки.

## Критерии приёмки

- AC-1 Переход уровней без видимой вспышки (пересоздание таргета ≤ 1 кадр).
- AC-2 На батарее уровень не выше 2 (проверка).
- AC-3 Автодеградация срабатывает за ≤ 3 с падения fps.

## Тест-план

Бенч: искусственная нагрузка → проверка смены уровня.

## Риски

Гистерезис может «застрять» на низком уровне → разрешить повышение после
30 с стабильных 58+ fps.
