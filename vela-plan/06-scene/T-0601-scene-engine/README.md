# T-0601 — Движок сцены

## 1. Цель

Одна модель сцены, из которой рендерится и полное изображение (в A), и
уменьшенное зеркало (в B) для стекла. Без этого стекло будет врать.

## 2. Модель сцены

```ts
type SceneSource =
  | { kind: 'photo';  assetId: string;   fit: 'cover'|'contain'; blur?: number }
  | { kind: 'slideshow'; assets: string[]; intervalMs: number; transition: 'fade'|'slide' }
  | { kind: 'video';  assetId: string;   loop: boolean; muted: true }
  | { kind: 'shader'; shaderId: 'aurora'|'mesh'|'void'|'custom'; params: Record<string, number> }
  | { kind: 'canvas2d'; scriptId: string }        // игра/интерактив (P6.4)
  | { kind: 'off' };                              // статичный цвет

interface SceneLayer {
  source: SceneSource;
  opacity: number;
  blend?: 'normal'|'screen'|'overlay';
  parallax?: { depth: number };      // 0 = статичен, 1 = ближний план
  mask?: 'none'|'vignette';
}
```

- `SceneDigest` (для mirror) строится из той же модели: цвета/изображение/кадр.
- Параллакс — сдвиг слоя по курсору с коэффициентом `depth`; реализуется в
  вершинном/фрагментном шейдере или через `transform` для фото.

## 3. Рендер

- WebGL2 контекст в A (одно полотно, слои рисуются в один проход).
- Фото/видео — текстуры, шейдер с `cover`-подгонкой, `dpr`-осознанный.
- Шейдерные сцены — фрагментный шейдер (fbm-шум, градиенты), время как uniform.
- Ограничение по качеству: `qualityLevel` (1–3) → разрешение текстуры, число
  октав шума, dpr-кап (1.0/1.25/1.5).

## 5. Критерии приёмки

- **AC-1** Модель валидируется: неизвестный `kind` → ошибка, не белый экран.
- **AC-2** `SceneDigest` строится из модели без обращения к пикселям A.
- **AC-3** Три уровня качества дают измеримую разницу GPU (30–50 %).
- **AC-4** Crossfade 400 мс без вспышки и без двойного рендера сцены.
- **AC-5** Слои с `parallax` двигаются плавно (≤ 1 кадр задержки).

автодеградация по fps (ST-0601-03).
