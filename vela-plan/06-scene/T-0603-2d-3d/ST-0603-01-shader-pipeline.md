# ST-0603-01 — Шейдерный пайплайн

## Цель

Добавление новой сцены = один GLSL-файл + запись в реестре.

## Реализация

1. `scene/gl/shader.ts`: компиляция вершинного (общий фуллскрин-квад) и
   фрагментного шейдера; кэш программ по `shaderId + quality`.
2. `uniforms`: общий блок `{ uTime, uResolution, uPointer, uTheme, uQuality,
   uParams }`; `uParams` — `vec4[8]` из параметров сцены (имена → индексы в реестре).
3. Реестр сцен: `{ id, fragment: string, paramsSchema }` — схема даёт автоформу
   настроек (используется в T-0402-02).
4. Ошибка компиляции: `getShaderInfoLog` → лог + фолбэк на `void`.
5. Горячая перезагрузка шейдеров в dev (через `import.meta.hot`).

## Критерии приёмки

- AC-1 Ошибка компиляции не роняет приложение (фолбэк `void`).
- AC-2 Добавление сцены требует только нового GLSL + запись в реестр.
- AC-3 `paramsSchema` генерирует рабочую форму настроек.

## Тест-план

TC-0603-02, TC-0603-04.

## Риски

Uniform-массив фиксированной длины ограничивает параметры 8 штуками на сцену —
достаточно, зафиксировать в схеме.
