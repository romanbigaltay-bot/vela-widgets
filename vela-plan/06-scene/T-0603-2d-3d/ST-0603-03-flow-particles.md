# ST-0603-03 — Flow

## Цель

Живая сцена с настоящим движением, остающаяся дешёвой.

## Реализация

1. `InstancedArrays` 2000 точек, позиции обновляются в вершинном шейдере по
   времени (без CPU-апдейта буферов — `uTime`-функция).
2. Форма частицы — `gl_PointSize` + круглая маска в фрагментном шейдере.
3. Реакция на курсор — притяжение/отталкивание в радиусе 200 px (uniform).
4. Параметры: количество (500–4000), скорость, размер, палитра.
5. Автодеградация: при fps < 45 — уменьшить количество вдвое (до минимума 500).

## Критерии приёмки

- AC-1 2000 частиц @1440p: 60 fps на GTX 1650.
- AC-2 Нет CPU-нагрузки на обновление частиц (проверка профилем: 0 мс в JS).
- AC-3 Реакция на курсор плавная, без «прилипания».

## Тест-план

Бенч: 3 количества частиц × 2 уровня качества.

## Риски

`gl_PointSize` ограничен драйвером (обычно 255) — не полагаться на большие
размеры, использовать несколько точек на частицу при необходимости.
