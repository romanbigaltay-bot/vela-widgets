# T-0603 — 2D/3D сцена

## 1. Цель

Живой абстрактный фон, который выглядит дорого и стоит дёшево: шейдерные
сцены с параллаксом, без загрузки тяжёлых движков.

## 2. Решение по OQ-03

**Собственный минимальный WebGL-слой, Three.js не используем** (на момент
планирования). Обоснование:
- все сцены — фуллскрин-квад с фрагментным шейдером; 3D-геометрия не нужна;
- Three.js ≈ 600 КБ gzip против ≈ 0 КБ (свой код); нужен мгновенный старт;
- контроль над `uniform` и качеством важнее удобства.

Пересмотр, если появится сцена с настоящей геометрией/освещением (тогда
кандидат — `OGL`, 40 КБ).

## 3. Сцены v1

| ID | Вид | Параметры |
|---|---|---|
| `aurora` | fbm-шум, 3 цветовые зоны, медленный дрейф | скорость, насыщенность, blur |
| `mesh` | сетка линий с волной, тонкая, тёмная | плотность, амплитуда |
| `void` | почти чёрный, лёгкое дыхание градиента | сила, оттенок |
| `flow` | частицы/поток (GPU-инстансинг, 2D) | число, скорость, размер |

- Параллакс за курсором — общий механизм: сдвиг UV/матрицы на `pointer * depth`.
- Палитра — из токенов темы; сцена уважает светлую тему (светлый вариант `aurora`).

## 5. Критерии приёмки

- **AC-1** 60 fps на 1440p при среднем GPU (GTX 1650), 45 fps на iGPU при
  уровне качества 1.
- **AC-2** Шейдеры компилируются без ошибок; ошибка компиляции → фолбэк `void`
  и лог, не чёрный экран.
- **AC-3** Параллакс ≤ 1 кадр задержки, без «дрожания» на 144 Гц.
- **AC-4** Уважение темы: в светлой теме сцена не «выжигает глаза» (проверка
  среднего luminanсе ≤ 0.85).
- **AC-5** Смена параметров в настройках применяется без перезагрузки шейдера
  (только uniform).
