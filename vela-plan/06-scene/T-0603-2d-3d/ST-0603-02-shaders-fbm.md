# ST-0603-02 — Шейдерные сцены

## Цель

Три сцены, которые не выглядят «дефолтным шейдером из туториала».

## Реализация

1. `aurora.glsl`: fbm с 3 октавами (4 на high), три цветовые зоны из палитры,
   медленный дрейф (`uTime * 0.02`), мягкое вертикальное затухание.
2. `mesh.glsl`: эквидистантная сетка (`fract`), волна по `sin(x*a + t)`, тонкие
   линии (сглаживание через `fwidth`), почти чёрный фон.
3. `void.glsl`: радиальный градиент с «дыханием» (sin с периодом 18 с), очень
   низкая контрастность, оттенок из темы.
4. Все — без резких краёв (антиалиасинг через `smoothstep`).
5. Светлая тема: отдельные цветовые константы (`uTheme`), проверенные по
   среднему luminanсе.

## Критерии приёмки

- AC-1 60 fps на GTX 1650 @1440p (все три).
- AC-2 Нет бандинга (проверка градиента на 8-битном выходе — добавлен дизеринг).
- AC-3 Светлая тема не «выжигает» (luminanсе ≤ 0.85).

## Тест-план

TC-0603-01, TC-0603-03.

## Риски

Бандинг на тёмных градиентах — обязательный дизеринг (шум ±0.5/255).
