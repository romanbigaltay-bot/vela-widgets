# T-0605 — Энергополитика

## 1. Цель

Сцена — самая дорогая часть приложения, и она должна уметь полностью
останавливаться. Это главный риск продукта (R-15).

## 2. Правила

| Условие | Действие |
|---|---|
| Fullscreen-приложение в фокусе | пауза видео, стоп шейдера (0 fps) |
| Батарея < 25 % | пауза, статичный кадр (последний) |
| Батарея 25–50 % | 30 fps, качество 1 |
| `locked` экран / suspend | полная пауза, освобождение GPU-контекста? (нет — сохраняем, но не рендерим) |
| Скрытие сцены пользователем | окно скрыто, 0 fps |
| Оверлей C активен | сцена на паузе (blur заморожен) |

## 3. Реализация

1. `ScenePowerPolicy` — единая функция `(power, foreground, visibility) -> SceneMode`
   (`active|reduced|paused`), тестируемая чисто.
2. Применение: A получает `scene.set_mode`, стоп/старт цикла, пауза видео.
3. Метрики: время в каждом режиме за сессию (для отладки батареи).
4. При возврате из `paused` — восстановление с текущего времени (не «промотка»).

## 5. Критерии приёмки

- **AC-1** Fullscreen → 0 fps сцены за ≤ 300 мс.
- **AC-2** Батарея: сцена выключена — 3.5 %/ч (замер 2 часа).
- **AC-3** Батарея < 25 % → пауза, последний кадр остаётся видимым.
- **AC-4** Возврат из паузы без «промотки» видео.
- **AC-5** Индикатор режима показывает текущее состояние (для отладки).

## 7. Риски

R-15 — если батарея всё равно уходит, единственный выход: отключать сцену
на батарее по умолчанию (решение принимается по фактическим замерам).
