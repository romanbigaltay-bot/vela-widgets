# ST-0605-03 — Индикатор и настройки

## Цель

Пользователь понимает, почему фон «замер» — и может это изменить.

## Реализация

1. В настройках: строка состояния «Сцена: активно / снижено / пауза (причина)».
2. Тумблеры: «Приостанавливать на батарее», «Приостанавливать в fullscreen»,
   «Качество сцены».
3. В трее — бейдж на иконке при `paused` (точка `--warn`).
4. Тост при первом переходе в `paused` (один раз за сессию), без спама.

## Критерии приёмки

- AC-1 Причина паузы видна в настройках.
- AC-2 Тост показывается один раз за сессию.
- AC-3 Изменение настроек применяется сразу.

## Тест-план

Ручной + скриншоты состояний.

## Риски

Индикатор в трее может раздражать → только точка, без анимации.
