## Негативные проверки

Зелёный линт сам по себе ничего не доказывает: конфиг мог сломаться и молчать.
Поэтому запреты проверяются «от обратного» — временным файлом с нарушениями.

| Что проверялось | Ожидание | Факт |
|---|---|---|
| прямой `invoke` из компонента | ошибка | ✓ `no-restricted-imports` |
| `console.log` в компоненте | ошибка | ✓ `no-console` |
| `requestAnimationFrame` напрямую | ошибка | ✓ `no-restricted-syntax` |
| `setInterval` напрямую | ошибка | ✓ `no-restricted-syntax` |
| `unwrap()` в рантайм-коде Rust | ошибка сборки | ✓ `unwrap_used = deny` |
| `unwrap()` в тестах Rust | разрешено | ✓ `cfg_attr(test, allow(...))` |
| Отказ доступа не лечится как порча | `is_corruption` = false | ✓ тест `access_errors_are_not_treated_as_corruption` |
| `FailOnCorruption` не трогает файл | байты на месте | ✓ тест `fail_on_corruption_does_not_touch_the_file` |
